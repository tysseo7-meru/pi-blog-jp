テストネットにRPCサーバーを公開、スマートコントラクト開発の基盤が進む

公開日：2026年4月8日

カテゴリ：お知らせ、開発者向け

元の英語タイトル：Pi Testnet RPC Server Released: Enabling Scalable Smart Contract Development

原文（英語）

このページは、Pi Network公式ブログの記事を平たい日本語で要約したものである。全文の翻訳ではない。正確な表現は原文（英語）を確認してほしい。

Pi Networkは、テストネット（本番前のテスト用ネットワーク）でRPCサーバーを公開した。RPC（Remote Procedure Call、アプリがブロックチェーンに問い合わせや指示を送り、結果を受け取るための窓口）サーバーは、Piの仕組みの中でスマートコントラクト（ブロックチェーン上で条件に応じて自動で実行されるプログラム）の開発、テスト、今後の本番導入を支える重要な基盤の節目である。

今回の公開は、Pi Day 2026で発表されたノードとプロトコルのアップグレードを土台とする。Pi Day 2026では、メインネット（本番ネットワーク）のブロックチェーンがプロトコル20にアップグレードされ、スマートコントラクト機能の土台が作られた。メインネットのプロトコルのアップグレードはその後も続き、現在はプロトコル21へのアップグレードが進んでいる。

RPCサーバーでできること

RPCサーバーは、アプリがリクエスト（要求）を送り、レスポンス（応答）を受け取ることでブロックチェーンと通信するための仕組みである。この基盤は、スマートコントラクトを使った実用的なアプリを作るうえで欠かせない。RPCサーバーは、スマートコントラクトとのやり取りについて、次の2種類を支える。

  • 読み取り専用の呼び出し（手数料は不要）：開発者は、口座の状態、残高、アプリ固有の情報といったスマートコントラクトのデータを、ガス手数料（ブロックチェーンを使う際の手数料）を払わずに問い合わせることができる。この操作はブロックチェーンの状態を変えず、RPCの接続先を通じて即座に実行される。
  • 状態を変えるトランザクション（手数料が必要）：コントラクトの処理を実行する、データを更新するなど、ブロックチェーンの状態を変える操作は、引き続き通常のトランザクション処理と、それに伴う手数料が必要である。

実際の利用場面の多くは、速くて無料の読み取りアクセスに大きく依存する。アプリとブロックチェーンの間の効率的な通信を可能にすることで、RPCサーバーは開発者に次のことを可能にする。

  • リアルタイムのブロックチェーンデータに頼る、反応の速いアプリを作ること
  • 管理された環境でスマートコントラクトの動きをテストし、再現すること
  • バックエンドのサービス（裏側で動く仕組み）とユーザー画面をPiのブロックチェーンとつなぐこと

開発者はテストネットでRPCサーバーを試せる

RPCサーバーは現在、Piテストネットで利用でき、開発者が調べてテストできる。開発者には実際に試すことが勧められている。テストネットでの性能と信頼性をもとに、RPCサーバーはメインネットでも公開される予定である。

ノード運営者は自分のRPCサーバーを追加できる

ノード運営者や、スマートコントラクトに依存するサービスを運営する事業者も、自分のRPCサーバーを追加できる。用途は、自分の内部利用専用でも、一般に公開する形でもよい。
