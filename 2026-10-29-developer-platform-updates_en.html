Pi Updates: Developer Portal Interface, BlockExplorer Token Tracking, SoloHost AI App Packaging, and PiVerify

Published: October 29, 2026

Categories: developer, update

Original article

This page is a plain-English summary of an article from the official Pi Network blog. It is not a full translation. Difficult words and expressions are explained in simple words. For the exact wording, see the original article.

Pi Network introduced several technical updates across its developer tools and products. They include improvements to the flow and screen of the Developer Portal, price tracking for Launchpad tokens in Pi BlockExplorer (a screen for looking up transactions and other records), AI help for packaging SoloHost apps, and PiVerify features.

Together, these improvements make it easier for developers to build on Pi, give a clearer view of ecosystem activity, and strengthen the base that supports the network.

Improved Developer Portal

Pi updated the Developer Portal and redesigned its screen, so developers can set up and manage their apps more easily.

The old checklist for getting started was replaced with a dedicated App Configuration (app settings) section. Settings such as the domain, API key (a key for connecting systems), the app wallet, and privacy information are now gathered in one place. The updated screen also makes it clearer how to move to important features and developer materials, such as Pi Sign-In, Ecosystem Listing (listing in the ecosystem), PiNet, and Pi Ad Network.

The Developer Portal connects an app to Pi's wider base, including user authentication (checking who a user is), Pi payments, and discovery in the ecosystem. By making these flows simpler, this update helps developers add Pi features more easily, prepare to publish an app, and manage it over time. Alongside the recently released developer features and unified documentation, these improvements are part of Pi's wider effort to lower barriers to app development and increase apps and usefulness for Pioneers (Pi users). They also support preparation for the upcoming Ecosystem Summit, by making it easier for developers to build and publish apps on Pi.

Token price tracking in Pi BlockExplorer

Pi BlockExplorer now includes past price tracking for Launchpad Testnet tokens. Pioneers and developers can now see how a token such as SLICE changed in price against Test-Pi over time. Future Mainnet tokens will also be tracked on this BlockExplorer screen after this feature is released. This update builds on the previous Pi Launchpad update. That update introduced price charts in the Launchpad app and explained how swaps in a liquidity pool (a system that holds funds for exchange) affect a token's price.

This feature supports Pi Launchpad's wider approach to ecosystem tokens. Ecosystem tokens are designed to help projects gain users and build tokens into their apps for real uses, such as access, payments, and rewards. The Pi that Pi receives from issuing a token does not go to the project that issued it. It goes into a liquidity pool with the ecosystem token. This creates a healthy base of liquidity (funds that can be exchanged) from the start.

By making this information available through BlockExplorer, Pioneers and the wider public can see Launchpad Testnet tokens and their price histories without access to the Pi Browser or a Pi account. This gives a clearer view of these systems. As with earlier Launchpad Testnet releases, this update also supports learning by Pioneers and helps Pi refine the Launchpad model before the first Mainnet token issue. These test tokens are only on Testnet, and they will never go to Mainnet.

AI help for packaging SoloHost apps

Pi introduced a new skill in the public SoloHost GitHub repository (a place where files are stored and shared). With it, developers can use AI coding help to help prepare an app for publication through SoloHost on Pi Desktop.

Before, developers had to prepare the setting files needed to publish an app through SoloHost by hand. With the new skill, a developer can give an existing app's public Docker image (a way to package an app together with the environment it needs to run) to AI help that supports agent skills, such as Claude Code, Cursor, or Codex, and package the existing app using the public Docker image. The AI help asks what features the app should offer, creates the two needed files, docker-compose.yml and config_options.yml, and checks their contents.

Developers can install the skill from the SoloHost GitHub repository. After that, they can use the created setting files to submit an app for publication through SoloHost.

By making the technical work needed to package an existing app simpler, this update lowers barriers for developers to bring more self-hosted software (software you run yourself) to Pi Desktop, and widens further the range of usefulness available to Pioneers. Publishing on SoloHost is a way for developers to deliver their apps to Pi's existing Node network of more than 420,000 Nodes (computers that help run the network), and to reach other Pioneers who are interested in running apps they run themselves on their own computers.

Expanded PiVerify identity verification features

PiVerify expanded its identity verification service for third-party companies. It now includes a check for duplicate faces and multiple liveness checks (checks that the person is really there at that time). These build on features already used in Pi's KYC system (identity verification; KYC means know your customer).

The duplicate face check helps a company find identity information in its own users that may be duplicated. The multiple liveness checks let a company ask for extra checks after a user's first identity verification. These features support stronger protection against fake accounts, fraud, and misuse. They matter in particular as it becomes more important to tell real humans apart from automated or dishonest activity.

As introduced in the Pi2Day 2026 announcement, PiVerify widens Pi's identity verification base, which uses AI and humans, to outside platforms. It lets companies use technology developed through verifying millions of Pioneers. Expanding these services supports verification of real humans beyond Pi's own ecosystem. Third-party clients paying in Pi for PiVerify services also creates extra usefulness for Pi, and helps widen the wider network of verified people.
