Pi Network Partners with CiDi Games to Accelerate Web3 Gaming Innovations and Expand Pi’s Real-World Use

Published: November 26, 2025

Categories: announcement

Original article

This page is a plain-English summary of an article from the official Pi Network blog. It is not a full translation. Difficult words and expressions are explained in simple words. For the exact wording, see the original article.

Pi Network announced a strategic partnership (a planned long-term working relationship) with CiDi Games. CiDi Games is a game platform company (a company that provides a base for games) that makes games linked to Pi that tens of millions of Pioneers (people who use Pi) can use. It also has a role in expanding the Pi platform so it can support other games and developers.

The partnership between Pi Network and CiDi Games is to expand the real-world uses of Pi and to further expand and support games in the ecosystem (the whole system of apps, users, and services around Pi). This work together will do the following.

  • Expand the situations where Pi is used in real life
  • Show developers a clear signal that Pi is putting serious effort into games at a large scale
  • Create new chances for Pioneers to use Pi and take part with Pi in daily life

The base of the partnership is that games fit Pi naturally and that Pi keeps working on games. The partnership adds to Pi's wider, joined-up work to grow the ecosystem.

An investment in CiDi Games by Pi Network Ventures makes the partnership stronger. This investment fits directly with the mission of Pi Network Ventures. It gives this chance to the CiDi Games team. The team has proven experience and skill in making games and running a platform, and it has an idea to set a new standard as the first Web3 game platform (a game platform that uses blockchain technology) to reach both large scale and long-term stability.

By joining Pi's reach around the world with CiDi Games' proven skill in making new kinds of games, the two sides are preparing the stage for a new era of Web3 games. In that era, Pi will be at the center of digital experiences that are fun, easy to use, and meaningful.

Strengthening Pi's game ecosystem through the partnership and investment

Pi joined with CiDi Games because games fit the Pi Network ecosystem completely. Games are also an area that Pi has already kept growing inside its ecosystem.

This partnership is part of Pi's wider work to expand the ecosystem. That work has many sides, is planned, and continues over time. It also includes investments by Pi Network Ventures. These investments help in two ways: they help bring more production onto the network, and they help create useful products that people want to use.

Why games fit the Pi ecosystem completely

Games are social, allow people to interact with each other, have flows of virtual money (money that exists only inside the game), and are a universal part of human experience. People play games for entertainment. Because of these points, games have a large enough market and are one area that can grow inside Pi's global social network. That network is a large group of people who have confirmed who they are, can use crypto assets (digital assets such as Pi), and are ready to interact and make transactions. The ecosystem also has tools to support game apps, developers, and businesses at a large scale.

For example, through the partnership between Pi and CiDi Games, games can gain users and spread from Pi's tens of millions of Pioneers. At the same time, the uses and use cases that developers create can, in turn, strengthen the Pi ecosystem through people's involvement, production, and new ideas. This cycle becomes possible.

Until now, Pi has supported the game area through hackathons (events where people build apps in a short time), app support programs, ready-made tools, and ways to earn money through the Pi Ad Network (Pi's advertising network). Pi also released FruityPi, a game linked to Pi payments, the Pi Ad Network, and Pi Wallet. FruityPi showed how Pi's existing features and basic-level uses can support apps in a real, long-lasting, and open way.

The partnership between Pi and CiDi Games strengthens Pi's ongoing work to create a game environment inside the Pi ecosystem that stands on its own and keeps going by itself. It takes these efforts to the next stage. It will make game links, social involvement, and new ideas large-scale across the whole network, and create new game and entertainment experiences in a Web3 environment.

Building the ecosystem from many sides and strategic investments by Pi Network Ventures

This partnership also shows the important role of Pi Network Ventures in Pi's wider ecosystem plan. Through strategic investments in companies like CiDi Games, Pi Network can work with experienced builders who focus on another industry, in this case games. They can help with both the uses of single apps and basic-level expansions that widen what developers and Pioneers can create on Pi.

This is one example of Pi's work from many sides to support a plan to expand real-world uses across the whole ecosystem. The range covers grassroots development (development by ordinary creators) through Pi App Studio to investments with a strong signal through Pi Network Ventures, from hackathons to support programs, and from technical support such as the Pi SDK (a set of tools that helps developers connect their apps to Pi) to ready-to-use business forms such as the Pi Ad Network. Pi also puts weight not only on single products or features, but on the added benefits that build up when different parts of the ecosystem move forward together, such as Pioneer involvement, platform growth, and reasons for developers to build.

Pi Network Ventures can join with experienced founders and fast-growing, new kinds of companies whose work strengthens and expands the benefits of the network for Pioneers. The partnership with CiDi Games is a clear example of how working together can keep speeding up Pi's long-term idea of an easy-to-use ecosystem centered on real uses.

CiDi Games: Building games linked to Pi and expanding the Pi platform

By joining CiDi Games' special skill in making new kinds of games with Pi's global community and full platform, this partnership creates a strong base to expand the real-world uses of Pi through games.

CiDi Games is building a set of high-quality games for the Pi ecosystem. The company is now developing the H5 Game Platform. This is a place where light HTML5 games (games that run in a web browser) are gathered, designed for easy involvement and casual play.

Pi is built directly into CiDi Games' works. Pi will become a central means for payments, transactions, and rewards inside the platform. An open framework (a shared base structure) that expands the Pi platform is also being developed by CiDi Games. This provides extra tools, APIs (a way for different software programs to connect and work together), and a platform for other game developers. It makes it easier for them to link their own games to Pi and to create a more unified game environment.

The first version of the product is planned to be tested in the first quarter of 2026 (January to March 2026), and the priorities for development are better performance, reflecting user feedback, and matching the ecosystem.

Pi Network and CiDi Games will keep sharing updates as development continues. At this time, this partnership is a big step toward expanding the uses of Pi and using games as a strong force for ecosystem growth.
