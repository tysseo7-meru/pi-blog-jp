Pi Ecosystem Summit Begins Today!

Published: November 17, 2026

Categories: announcement, developer

Summit Day 1: Developer platform, ecosystem initiatives, and showcases

The first-ever Ecosystem Summit for Pi Network has begun. At this three-day online summit, there are announcements of a new developer platform, conversations with developers, and technical demos, and tools and apps that widen real utility across the Pi ecosystem are introduced.

The video program for this day is as follows. The videos were released at 8:00 AM (PST) / 4:00 PM (UTC).

  • Opening remarks: Pi Network founder Chengdiao Fan
  • Pi AI / MCP demo: founder Nicolas Kokkalis demonstrating the Developer Web Console and MCP tools for AI-assisted app development
  • Pi subscription smart contract demo: a demonstration of the on-chain subscription feature for repeated payments
  • OpenMind's x402 demo: a demonstration of x402-enabled Pi payments through RoboPay on Pi Testnet
  • Conversation with CiDi Games: founder Chengdiao Fan and CiDi Games co-founder Jeremy Ng talked about building on Pi, game utility, and the developer experience

The summit continues tomorrow, November 18, 2026, with additional technical demos, developer conversations, and new announcements.

On November 19, 2026, Pi Next, Pi's new hackathon (an event where developers compete to build intensively in a short period), begins. The total prize pool is 200,000 USDT. Developers get the chance to build apps with real uses for a large, identity-verified user base, using Pi's developer platform, SDK (software development kit), and built-in Pi authentication and payment features.

Building and growing apps on Pi

In an era when AI makes development much more accessible, reaching users and keeping them using an app are important challenges for developers. Pi addresses these challenges in two ways: by providing tools that make app development easy, and by providing an existing ecosystem where developers can connect their products with real users.

Pi gives developers access to a global community of more than 60 million engaged Pioneers (Pi users), an ecosystem built on a distributed base of people, and a network of more than 420,000 Nodes. Pi's platform also provides developers with features such as user authentication, Pi payments, verified identity information, AI-ready development, monetization, and app discovery. This helps deliver apps to the established Pioneer community and turn Pi's platform and gathered resources into utility.

AI-assisted development: the new Developer Web Console and MCP

Developers and creators can now use AI agents (AI that receives instructions and carries out work) to build and register apps, connect them with Pi's APIs (interfaces that connect apps to each other), and apply to list their apps in the Pi ecosystem. This new AI-assisted development experience makes the flow of bringing an app to Pi more efficient, and reduces much of the effort and burden that the traditional developer registration and integration used to take.

Through a new browser-based Developer Web Console, which has Pi's developer tools built on the Model Context Protocol (MCP — a common standard that connects AI with outside tools), developers can connect a compatible AI coding agent to Pi's developer tools and, with instructions in natural language, have it do the matching setup and integration work. This covers creating and registering Pi apps, configuring app settings and URLs, and implementing Pi APIs such as Pi Authentication and Pi Payments.

Instead of moving by hand between multiple setup steps, documentation pages, and developer screens, developers can leave much of the technical setup and implementation to the AI agent, with human approval where needed. The Developer Web Console also provides a central screen for managing apps and accessing developer materials, and it supports both traditional development and AI-assisted development. These features are for developers building new apps and for developers bringing existing apps to Pi, including professional developers, startups, and creators who use AI coding tools.

Seen more widely, this system lowers the technical barriers to building on Pi, makes the platform easier for a wider range of creators to use, and simplifies the development and integration flow. On this day, Pi Network founder Dr. Nicolas Kokkalis demonstrated how an AI agent interacts with Pi's developer tools to register and configure an app and connect it with the Pi platform.

A new ecosystem growth incentive and marketing budget

Pi Network announced the App Growth Initiative, a new initiative with a marketing budget of up to 20 million Pi. Supported by the Pi Foundation, this initiative can help developers gather users and encourage participation in Pi ecosystem apps.

In this initiative, eligible developers can gain access to a part of this marketing budget, based on their app's content and track record. Developers can then use incentives funded by Pi to reach identity-verified users and get them involved, without preparing the rewards themselves. For example, if an eligible identity-verified Pioneer invites another eligible identity-verified Pioneer to use a participating app, both the inviting Pioneer and the new user may each receive Pi from the Foundation-supported incentive budget for the eligible participation. Details of the eligibility conditions and reward amounts will be announced later.

This program is designed so that developers can reach Pi's existing network of users who have completed identity verification and migrated to Mainnet, without having to fund and build their own referral and user-acquisition systems. The whole incentive budget may be divided among participating apps based on factors such as app quality, utility, and proven user engagement, and apps with a strong track record may receive larger support.

Seen more widely, the App Growth Initiative aims to extend the base of Pi's network growth to ecosystem developers. It puts funds into user growth mechanisms and applies part of the strategy Pi developed while growing its own network. The initiative channels resources through proven growth mechanisms and helps apps gain and engage real users. This approach improves support for developers, and at the same time helps ensure that resources for the network's ecosystem growth are used efficiently and tied to real user participation.

Developer incentives and the redesigned Pi App Directory

Pi is introducing a new system that encourages developers to build high-quality, engaging apps. Developer incentives generally reward developers through exposure, financial incentives, and status. Exposure provides better distribution opportunities. Financial incentives may include support for development costs or discounts. Status rewards provide a measure of a developer's reputation. A financial example is the subsidized pricing of Pi App Studio for apps by creators who show real utility and gather real users.

As part of putting these developer incentive systems into practice, Pi has begun a major redesign of the Pi App Directory (the app listing). It introduced new ways for Pioneers to discover apps and widened the exposure opportunities for developers to reach users across the ecosystem.

In the directory, while keeping Ecosystem Directory Staking (a system where people stake Pi to support apps, which affects their ranking in the directory) as the central discovery and ranking mechanism, additional discovery sections were introduced that feature apps based on user interest, growth, and engagement.

  • Bookmarked Apps: a section that makes it easy for Pioneers to access and return to their favorite apps
  • Pi-Staked Apps: a section that keeps the existing app ranking mechanism based on community staking (staking Pi to support an app)
  • Rising Apps: a section that features new apps that are gaining momentum
  • Discover: a section that introduces Pioneers to apps they have not tried yet
  • Pioneers Keep Coming Back: a section that features apps judged to be used repeatedly

These updates provide paths for new apps to gain exposure based on their track record. Developers are encouraged to be rewarded with more exposure by building better, more engaging apps.

Taken together, these changes show a wider effort to strengthen app distribution within Pi. By increasing the chances for apps to gain exposure through real user engagement, the redesigned app directory encourages developers to put useful, high-quality products first, and helps Pioneers discover more ways to use Pi.

Pi Launchpad, DEX, and AMM come to Mainnet in the first quarter of 2027

The Pi Launchpad (a system that supports token launches), the DEX (decentralized exchange — a place to trade without an operator in between), and the AMM (automated market maker — a system that sets prices automatically and makes exchanges happen) will launch on Mainnet in the first quarter of 2027. These features are on Testnet and have gone through several rounds of improvement. They provide additional platform support for token launches in the ecosystem, and support developers and apps that bring in tokens for specific utility purposes.

This commitment gives a timeframe so that developers and ecosystem participants can prepare for token launches on Mainnet. As Pi keeps introducing new tools, materials, and programs that make app development easy and involve a wider range of developers, the Pi Launchpad, DEX, and AMM provide additional platform support for the next stage of ecosystem development.

The first-quarter-2027 timing also ensures time for projects that could become Launchpad candidates, including projects taking part in upcoming Pi hackathons, to build and prepare their apps toward the possibility of a token launch.

On-chain subscription smart contracts

Pi's on-chain subscription smart contracts (programs that run contract terms automatically) let developers build repeated payment services into their apps. They cover uses such as service memberships, games, online tools, distribution platforms, and other subscription-type products.

This feature was first introduced on Pi Testnet in April 2026, and it addresses challenges common to blockchain-based subscriptions. Subscriptions are widely used in traditional digital services, but implementing them on a blockchain often required approval for each transaction, preparing funds in advance, and extra platform support.

In Pi's implementation, users can approve a set spending budget and subscription period, such as six months' worth for a monthly subscription, and do not need to sign at each renewal. Users can extend or cancel a subscription, and funds stay in the user's own wallet until each payment is processed; they are not locked or moved in advance.

Now, in addition to the smart contract itself, the related supporting platform in the Pi Wallet and the developer platform has also been implemented, covering the whole subscription experience for users and developers.

In Pi Network's Day 1 demo, it was shown how a developer can build this Testnet feature into an app, including subscription setup, user approval, and payment processing.

x402 payments integrated on Pi Testnet

x402 is an open payment standard that lets a service request payment as part of a web interaction, using the HTTP 402 'Payment Required' response, without needing a traditional checkout process. As AI agents become more able to work on their own, x402 enables new ways for software and machines to trade with each other more efficiently, including paying for access to digital services and paying for the completion of automated work.

Pi Network implemented support for x402 payments on Pi Testnet, so that apps, APIs, AI agents, and automated services can make Test-Pi payments through programs. The specification Pi submitted covers both Pi Testnet and Pi Mainnet, and details of the Mainnet availability timing will be shared before the launch.

On this day, OpenMind demonstrated the integration of its RoboPay platform with Pi payments, using the x402 payment standard. The demo showed how a developer can set Pi up as an accepted payment method, and how an automated client can request an action from a robot or service, pay in Test-Pi, and trigger the requested action when the payment is completed.

Pi has submitted the technical specification for x402 payments to the x402 Foundation, and it is in the review process for inclusion in the official x402 specification. As this day's demo showed, the integration itself is already working.

Other developer platform features

In addition to the features demonstrated at this day's summit, Pi introduced several more features to support developers building apps in the ecosystem.

Improved Pi app onboarding and deep links (links that lead directly to a specific app or page): Pi improved the onboarding experience for users who access ecosystem apps through PiNet links. If a person who has not installed Pi Browser receives a PiNet app link and opens it, they are guided to download Pi Browser through the App Store or Google Play. After installing and opening Pi Browser, they move to the original Pi app or page they were meant to visit. For example, if a person outside Pi Network is invited by a Pioneer to a game in a Pi app, right after onboarding that person can play that game's session directly, without having to find the way to the game themselves.

This smooth deep-link feature ensures continuity of the Pi app experience for users outside the network, lowers the drop-off rate in user conversion for growth initiatives, and makes it easier for developers to bring people directly to their apps.

Notification Center: Pi is introducing an in-app Notification Center. With it, developers can send ecosystem notifications to users from their own Pi apps, and users can see notifications in one place inside the Pi ecosystem. All ecosystem developers can start building in this feature now, and can send users notifications related to their app, support interaction, and encourage continued engagement. These notifications are delivered inside Pi Browser, not as push notifications to the user's phone.

Standard support for push notifications is the next stage of the Notification Center. To prevent abuse and ensure good-faith use, more selective and restrictive rules will apply to developers.

During the first rollout period, an app can send notifications to up to 20 users without extra approval. Developers who want to notify more users need approval. This is a temporary measure to prevent abuse as the new feature spreads.

What to build next

Day 1 of the Ecosystem Summit was a session that showed Pi's continuing effort to strengthen the tools, platform, and incentives that improve the developer experience and support ecosystem development. Taken together, these efforts help developers build useful apps, reach real users, and create more opportunities for Pioneers to take part in the ecosystem.
