Pi Testnet RPC Server Released: Enabling Scalable Smart Contract Development

Published: April 8, 2026

Categories: announcement, developer

Original article

This page is a plain-English summary of an article from the official Pi Network blog. It is not a full translation. Difficult words and expressions are explained in simple words. For the exact wording, see the original article.

Pi Network has released an RPC server on the testnet (the test network used before production). The RPC (Remote Procedure Call, the window through which an app sends questions and instructions to the blockchain and receives the results) server is an important foundation milestone that supports the development, testing, and future production introduction of smart contracts (programs that run automatically on the blockchain according to conditions) within the Pi ecosystem.

This release is built on the node and protocol upgrades announced at Pi Day 2026. At Pi Day 2026, the Mainnet (production network) blockchain was upgraded to protocol 20, and the foundation for smart contract functions was created. The Mainnet protocol upgrades have continued after that, and an upgrade to protocol 21 is currently in progress.

What the RPC server can do

The RPC server is a system for apps to communicate with the blockchain by sending requests and receiving responses. This foundation is essential for building practical apps that use smart contracts. For interaction with smart contracts, the RPC server supports the following two types.

  • Read-only calls (no fee required): developers can ask for smart contract data, such as account states, balances, and app-specific information, without paying gas fees (the fees for using the blockchain). This operation does not change the state of the blockchain, and it is carried out immediately through the RPC connection point
  • Transactions that change the state (a fee is required): operations that change the state of the blockchain, such as executing a contract's processing or updating data, still require normal transaction processing and the fees that come with it

Many real use situations depend heavily on fast, free read access. By enabling efficient communication between apps and the blockchain, the RPC server lets developers do the following.

  • Build responsive apps that rely on real-time blockchain data
  • Test and reproduce smart contract behavior in a managed environment
  • Connect back-end services (the systems running behind the scenes) and user screens with the Pi blockchain

Developers can try the RPC server on the testnet

The RPC server is currently available on the Pi testnet, and developers can examine and test it. Developers are encouraged to actually try it. Based on its performance and reliability on the testnet, the RPC server is planned to be released on Mainnet as well.

Node operators can add their own RPC server

Node operators, and businesses that run services depending on smart contracts, can also add their own RPC server. Its use may be only for their own internal use, or in a form open to the public.
