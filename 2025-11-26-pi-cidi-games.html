PiがCiDi Gamesと組んで、ゲームでPiの使い道を広げる

公開日：2025年11月26日

カテゴリ：お知らせ

元の英語タイトル：Pi Network Partners with CiDi Games to Accelerate Web3 Gaming Innovations and Expand Pi’s Real-World Use

原文（英語）

このページは、Pi Network公式ブログの記事を平たい日本語で要約したものである。全文の翻訳ではない。正確な表現は原文（英語）を確認してほしい。

Pi Networkは、CiDi Gamesとの戦略的な提携を発表した。CiDi Gamesは、数千万人のパイオニアが使える、Piと結びついたゲームを作るゲーム基盤の会社であり、ほかのゲームや開発者を支えられるようPiの基盤を広げる役割も持つ。

Pi NetworkとCiDi Gamesの提携は、Piの現実の使い道を広げ、仕組みの中のゲームをさらに広げ支えるためのものである。この協力は次のことを行う。

  • Piの現実の利用場面を広げる
  • Piが大規模にゲームに力を入れているという明確な合図を、開発者に示す
  • パイオニアが日常的にPiを使い関わる新しい機会を作る

ゲームへのPiの自然な適合と継続的な取り組みが提携の土台であり、仕組みの成長へのPiのより広い、連携した取り組みを補う。

Pi Network VenturesによるCiDi Gamesへの投資は、提携をさらに強める。この投資は、Pi Network Venturesの使命に直接沿うものであり、ゲーム開発と基盤の運営で実証された経験と能力を持ち、規模と持続可能性の両方を達する最初のWeb3ゲーム基盤となる新たな基準を作るという考えを持つCiDi Gamesチームに、この機会を提供する。

Piの世界的な広がりと、革新的なゲーム作りで実証されたCiDi Gamesの能力を組み合わせることで、両者はWeb3ゲームの新しい時代の舞台を整えている。その時代では、Piが楽しく、利用しやすく、意味のあるデジタルの体験の中心に位置する。

提携と投資でPiのゲームの仕組みを強める

PiがCiDi Gamesと組んだのは、ゲームがPi Networkの仕組みに完全に合うためであり、ゲームはPiがすでに仕組みの中で育て続けてきた分野でもある。

この提携は、仕組みの拡大に向けたPiのより広い、多面的で、戦略的で、継続的な取り組みの一部である。これには、ネットワーク上でより多くの生産を取り込むことと、有用で関わりたくなる製品の創出に貢献することの両方に役立つ、Pi Network Venturesの投資も含まれる。

ゲームがPiの仕組みに完全に合う理由

ゲームは社交的で、双方向で、仮想のお金の流れを持ち、人間の体験として普遍的である。人々は娯楽のためにゲームを遊ぶ。これらの要素により、ゲームは十分に大きな市場を持ち、Piの世界的な社会ネットワークの中で育ちうる分野の一つとなっている。それは、関わり取引する準備ができ、暗号資産が使え、本人確認済みの人々の大きな集まりであり、大規模にゲームアプリ、開発者、事業者を支える道具を備えた仕組みである。

たとえば、PiとCiDi Gamesの提携により、ゲームがPiの数千万人のパイオニアから利用者と広がりを得る一方で、開発者が作る使い道と利用場面が、今度は関わり、生産、革新によってPiの仕組みを強めるという循環が可能になる。

Piはこれまで、ハッカソン（短期間でアプリを作る開発行事）、アプリの育成計画、あらかじめ用意された道具、Pi Ad Networkを通じた収益化によって、ゲーム分野を支えてきた。Piはまた、Piの支払い、Pi Ad Network、Pi Walletと連携したゲームであるFruityPiを公開し、既存のPiの機能と基盤レベルの使い道が、アプリを具体的で、持続可能で、開かれた形で支える方法を示した。

PiとCiDi Gamesの提携は、Piの仕組みの中で成り立ち自ら続いていくゲーム環境を作るというPiの継続的な取り組みを強め、これらの努力を次の段階へ進める。ゲームの連携、社交的な関わり、革新をネットワーク全体で大規模にし、Web3環境で新しいゲームと娯楽の体験を作る。

多面的な仕組みづくりと戦略的なPi Network Venturesの投資

この提携は、Piのより広い仕組みの方針におけるPi Network Venturesの重要な役割も示している。CiDi Gamesのような会社への戦略的な投資により、Pi Networkは、今回の場合はゲームといったほかの産業に特化した経験ある作り手と協力できる。彼らは、個々のアプリの使い道と、開発者とパイオニアがPi上で作れるものを広げる基盤レベルの拡張の両方に貢献できる。

これは、仕組み全体で現実の使い道を広げる計画を支えるPiの多面的な取り組みの一例である。その範囲は、Pi App Studioを通じた草の根の開発から、Pi Network Venturesを通じた合図の強い投資まで、ハッカソンから育成まで、Pi SDKといった技術支援から、Pi Ad Networkのようなすぐに使える事業の形まで及ぶ。Piは、単一の製品や機能だけでなく、パイオニアの関わり、基盤の成長、開発者への動機といった仕組みの異なる部分が共に進むときに生まれる、積み重なる利点にも重点を置いている。

Pi Network Venturesは、経験ある創設者や、急成長する革新的な会社と組むことができる。その会社の仕事が、パイオニアにとってのネットワークの利点を強め、広げるものである。CiDi Gamesとの提携は、協力が、使い道を中心とした利用しやすい仕組みというPiの長期的な考えを、どう加速し続けられるかを示す明確な例である。

CiDi Games：Piと結びついたゲームを作り、Piの基盤を広げる

革新的なゲーム作りにおけるCiDi Gamesの専門性と、Piの世界的なコミュニティと包括的な基盤を組み合わせることで、この提携は、ゲームを通じてPiの現実の使い道を広げる強い土台を作る。

CiDi Gamesは、Piの仕組みのための質の高いゲームの集まりを作っている。同社は現在、H5 Game Platformを開発している。これは、関わりやすく気軽な遊びのために設計された、軽いHTML5ゲームの集まる場所である。

PiはCiDi Gamesの作品に直接組み込まれ、基盤の中での支払い、取引、動機の中心的な手段となる。Piの基盤を広げる開かれた枠組みも、CiDi Gamesによって開発されている。これは、ほかのゲーム開発者のための追加の道具、API（ソフト同士をつなぐ窓口）、基盤を提供し、自らのゲームをPiと連携させ、より統一されたゲーム環境を作ることを簡単にしている。

製品の最初の版は、2026年第1四半期にテストが予定されており、開発の優先事項は、性能の最適化、利用者の声の反映、仕組みとの整合である。

Pi NetworkとCiDi Gamesは、開発が続くにつれて続報を共有していく。現時点では、この提携はPiの使い道を広げ、仕組みの成長の強力な原動力としてゲームを解き放つことに向けた大きな一歩である。
