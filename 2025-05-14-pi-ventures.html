Pi Network Venturesが始動、1億ドルでスタートアップに投資

公開日：2025年5月14日

カテゴリ：お知らせ

元の英語タイトル：Launching Pi Network Ventures: Investing $100M in Innovative Startups

原文（英語）

Pi Foundationは、Pi Network Venturesの正式な開始を発表した。これはPiと米ドルで1億ドルの開発の取り組みであり、Piの使い道、普及、現実での影響を進めるものを含む、スタートアップ（新しい企業）や事業に戦略的に投資するものである。

Pi Network Venturesは、Pi Foundationを通じて設けられる。Pi Foundationは、Piエコシステム（Piに関わるアプリやサービスの集まり）の長期的な発展を導き、将来にわたってネットワークの持続可能性と機能を支えることを目的とした、所有者のいない組織である。この取り組みのために確保されたPiは、財団の準備分として特に割り当てられたトークンの10%から出る。オープン・ネットワーク（外部とつながる本番ネットワーク）が始まり外部との接続が有効になった今、この一歩は、影響の大きい使い道作りと現実への組み込みへの扉を開くものである。

Pi Network Venturesは、Piを広く持たれているトークンから、広く使われるトークンへ変えることに力を入れた、戦略的な取り組みである。

Pi Network Venturesの狙い

Pi Network Venturesは、中心となる3つの目標を持って作られた。

  • Piの使い道を増やす：Piを自社の製品、サービス、顧客体験に組み込むスタートアップや事業を支える。
  • 世界の生産をもっとPi Networkに乗せる：アプリ、取引、会社の形を問わず、現実の生産の過程を生み出すスタートアップや企業に早い段階で投資し、その過程をPiに乗せる。
  • Piを現実の世界へ持ち込む：広く行き渡り、利用しやすく、使える暗号資産としてのPiならではの価値を示す、現実の利用場面と応用を後押しする。

可能性の高い創業者、スタートアップ、企業に動機と資源をそろえて提供することで、この取り組みは革新と普及が循環する仕組みを作ることを目指す。それは、作り手、事業、そして最も重要なものとして、世界中のパイオニアのコミュニティに利益をもたらすよう設計されている。

Pi Network Venturesは、使い道を増やしPiエコシステムを後押しするPiの多様な高い水準の戦略の一部である。目立つ投資と育成が、草の根の使い道作りやエコシステムの動きと並行して働く。目立つ投資と育成は通常、非常に選ばれた基準に基づき、質の高い少数のスタートアップや事業を対象として支える。一方、草の根の動きはPiの既存のコミュニティを活かし、大きな規模で数多くの使い道作りの試みを生み出す可能性がある。Piは両方の戦略を用いる。Pi Network Venturesは前者に属し、ハッカソン（短期間で開発者が集まって作品を作る催し）や、使い道作りを規模拡大する他のあらゆる土台は後者に属する。

作り手を、始まりから規模拡大まで支える

Pi Network Venturesは、初期段階のスタートアップから、シリーズB（事業が成長段階に入った時期の資金調達）以降のベンチャーまで、幅広い企業への投資を考えている。この広い範囲により、可能性の高い革新者に加え、規模を広げ実績のある事業にも接する機会が増え、それぞれがPiの使い道を高める機会を増やす。

Pi Network Venturesは、ほとんどの暗号資産エコシステムのプログラムと、少なくとも2つの重要な点で異なる。第一に、ブロックチェーンを土台とするスタートアップも投資先に含まれるが、投資は一般の技術分野にも大きく力を入れる。生成AI（文章や画像などを作る人工知能）とAIの応用、FinTech（金融と技術を組み合わせた分野）、組み込み型の支払い、電子商取引の土台、マーケットプレイス（売り手と買い手をつなぐ場）、ソーシャルネットワーク、現実の消費者向けと企業向けの応用が含まれる。

Piを受け付ける世界の電子商取引の土台から、アクセスやクレジットにPiを活かすAI対応サービス、ロイヤルティプログラム（利用に応じた特典の仕組み）にPiを組み込む従来型の事業まで、現実での使い道とエコシステムの前進を進められる企業について、Pi Foundationはそれを支える投資の機会を探る考えである。

第二に、Pi Network Venturesの投資の進め方は、対象の発掘、選定、審査の過程などについて、シリコンバレーの従来のベンチャーキャピタル（成長が見込まれる新しい企業に投資する会社）のやり方を映すことを意図している。影響が大きく、既存のやり方を変えるスタートアップや事業を見つけ、支えるよう設計されている。

パイオニアにとっての戦略的な利益

Pi Network Venturesは、パイオニアのコミュニティを中心に置いて作られた。Pi Foundationが考える、パイオニアとコミュニティへの利益は次のとおりである。

  • 自分のPiの使い道が増える：最も重要な利益は使い道が増えることである。Piを受け付け、製品、サービス、取引、体験といった現実の応用に組み込む事業が増えるほど、Piをより多様な方法で使えるようになる。
  • より強いエコシステム：事業がPiを取り入れると、新しい利用者と利用場面をもたらす。これにより、実際の活動と使い道に沿った使い方を保ちながら自然な成長が生まれ、より強いエコシステムになる。より強いエコシステムは、利用者、作り手、働き手、起業家としてパイオニアが参加する機会を増やす。
  • 質の高い組み込みへの動機付け：Pi Foundationは、分野と地域を問わず、Piを組み込むものを含む、可能性の高いスタートアップと一流の事業への投資に力を入れる。この姿勢は作り手を引き付け、規模を増やし、ネットワークの展望を広げ、戦略的で持続可能な方法で普及を早める。
  • ネットワーク効果の働き：エコシステムに加わる事業はどれも、他の全ての参加者に価値を加える可能性がある。パイオニアは新しいサービスを使えるようになり、開発者は道具と着想を増やし、事業はPiの利用者層に接する。この積み重なる成長の効果が、Piを開かれたばかりのネットワークから、分散型の使い道の広く受け入れられた標準への移行を助ける。

世界最大級の暗号資産の利用者層へのアクセス

Pi Network Venturesが投資する可能性のある企業は、暗号資産の分野でも従来のベンチャーキャピタルでも非常にまれなものを得られる可能性がある。資金とともに市場へのアクセスが付いてくることであり、スタートアップ作りで欠かせないとよく言われる2つの要素に対応できる可能性がある。投資先の企業は、200を超える国と地域にわたる数千万人のPi Networkの利用者という、大きく、活動的で、KYC（本人確認）を終えた利用者層に接する機会を持ち、そのうち1900万人を超える人がすでにPi KYCで本人確認を終えている。

この世界的な利用者層は、事業にとっての資産であるだけでなく、競争上の強みにもなり得る。ネットワークによる成長、顧客からの意見が循環する仕組み、他では不可能な独自のトークンの仕組みを可能にする場合がある。

投資の進め方

投資は一般に米ドル建ての金額で表されるが、Pi Network Venturesは投資の大部分をPiそのものの形で直接行うことを目指す。エコシステムに加わる企業は、自らが強くし育てている通貨そのもので動機付けられることになる。

なお、Pi Network Venturesの投資は、世界に価値を生み、世界中でPiを使う方法を増やすのに最も適した立場にあると考えられる相手に、より広い期間にわたって資金と戦略的な価値の両方を提供することを意図している。Pi Foundationは、応募者の質と、この取り組みに受け入れられるスタートアップの数によっては、1億ドルの全額を投資する義務を負わない。Pi Network Venturesは時間をかけて投資を行う場合があり、いつでも投資をやめる場合がある。

オープン・ネットワークの転機

オープン・ネットワークの開始は、Piを新しい時代へ連れて行った。今、Pi Network Venturesが整ったことで、Pi Foundationは、Piの世界的な使い道を支え育てるという使命に、さらに力を入れることができる。

スタートアップや事業に投資することで、Piは、Piを使って作り、組み込み、革新する多くの開発者を後押しし、現実での使い道をもたらすことを目指す。Pi Network Venturesの投資は、世界中から利用でき、コミュニティ主導で、経済的に意味のある計画に力を入れる革新者を求めるものである。
