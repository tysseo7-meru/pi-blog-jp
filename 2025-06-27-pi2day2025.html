Happy Pi2Day 2025という挨拶で記事は始まる。

この日、Piは2つの大きな機能を公開した。（1）AIが進む中で世界が直面する問題を、ブロックチェーンとAIの両技術に基づいて解こうとし、パイオニアがPiアプリと有用性に貢献し、関わり、支える機会を広げるAIアプリの土台と、（2）ステーキング（預けること）の仕組みを通じて、パイオニアと事業者がPiアプリと有用性を支えられるようにする、もう1つの土台レベルの有用性である。

加えて、さまざまな技術と製品の更新が公開され、新しいPi2Day Ecosystem Challengeも始まった。このチャレンジは、パイオニアを新しい公開内容とPiの仕組みの機能へ案内し、デジタル賞品が得られるものである。

Pi2Dayの公開内容を述べる前に、今週初めにコミュニティへ投げかけられた「生成AIはPi Networkとどう関係するのか」という、AI、ブロックチェーン、Pi Networkについての問いが掘り下げられている。

AIが進む世界へのPiの解決策

ブロックチェーンを含むあらゆる技術の究極の有用性は、人類の根本的な問題を解くことにあるとされている。現在、AIの基盤では画期的な進展が起きる重要な局面にある。しかし、世界はまだ解かれていない次の問題に直面している。

  • AIの基盤と実際の生産の間にある、AIアプリ層の未熟さ
  • 人間の労働と知性の役割についての明確さの欠如
  • AIが前例のない量の生産を生み得る、AIが広く行き渡った世界における人間の幸福についての未解決の問いと、その結果の利益が、平等と公平の水準を許容できる範囲に保ち、または改善する形で人間にどう配られるか

Piは、AIとブロックチェーンの両技術を使うことで、世界はこれらの問題を解けると考えている。Piの見方では、両技術の交わりは、「分散型AIアプリ」という典型的な理解を超えて広がる。その理解は、AIの説明責任のための分散したデータ、計算、運営、所有に狭く焦点を当てることが多い。これらの側面も重要ではあるが、Pi Networkはブロックチェーンのより根本的な有用性として、社会的配分と再配分のための、規模を広げられ身近な解決策を見る。そのためPiは、ブロックチェーンとAIについてより広い展望を強調する。すなわち、ブロックチェーンを通じて、AIが生んだ生産をマクロな水準で分散させることである。ブロックチェーン技術を通じて、AIによる生産は、暗号ネットワークの中で人間の間に公平かつ包摂的に配られるべきであり、人間の幸福、経済的公平、AI主導の将来における人間知性の持続可能な役割をめぐる中核的な課題に取り組むものである。

この展望を実現するには、いくつかの重要な要素が必要である。第一に、本物であることが確立され、本物の人間とAIの存在を正確に見分け、配分が本物の人間へ届くようにしなければならない。第二に、進んだAI基盤と実用的な現実の生産をつなぐ、栄えて豊かなAIアプリ層が必要であり、作り手がブロックチェーンと組み合わさった革新的なAIアプリを簡単に作れるようにすることが求められる。第三に、これらのアプリを広く配り、多くの人が実際に使えるようにし、持続可能な事業の形を可能にする、活気ある社会的なネットワークが不可欠である。最後に、ブロックチェーン本来の特徴である説明責任と透明な権利管理を生かすことで、これらのアプリが生んだ生産が、仕組みの中の本物の人間利用者へ直接かつ公平に利益をもたらすことが確実になる。

Pi Networkは、必要な重要な土台要素をすでに確立しており、これらの課題に効果的に取り組む独自の位置にあるとされている。本物であることについては、Piは独自のKYC（本人確認）の仕組みを開発し、すべてのアカウントがPiメインネット（本番ネットワーク）へ参加する前に本人確認を通過することを求め、コミュニティにおける人間らしさの高い水準を確保している。現在、Pi KYCで本人確認が処理された後、1,370万人を超える人がPiメインネットへ移行している。大きな社会的なネットワークの必要に応えるため、Piは、200を超える国と地域で6,000万人を超える活発なメンバーを持つ、世界最大級の暗号対応の社会的なネットワークの1つを有している。

ブロックチェーンの説明責任と透明な特徴については、Piはブロックチェーンプロジェクトとして始まり、採掘の仕組みに公平な設計原則を用い、ネットワークの利益が広く身近であり、コミュニティに包摂的に共有されるようにした。最後に、栄えて豊かなAIアプリ層を促すため、この日、Piは生成AIの力を活用したPi App Studioを正式に公開し、技術者だけでなく作り手が、ブロックチェーンと組み合わさった革新的なAIアプリを簡単に作り公開できるようにした。Pi App Studioを支えるものとして、Pi Ad Network、.pi Domains、Pi Walletといった既存のPi製品に加え、この日公開されたEcosystem Directory Staking機能が、これらのアプリの実際の利用をさらに可能にし、Piの仕組みの中で持続可能な事業の形を確立する助けとなる。

Pi App Studio：AI時代の新しいアプリ作りの形

Pi App Studioは、多くの技術者が共有する展望、すなわち誰もが技術的な背景を必要とせず、人間の言語を使ってアプリを作り運営できる世界を実現しようとする試みの1つである。生成AIの力に加え、現在の他の生成AIによる雰囲気任せのプログラミングの土台とPi App Studioを分ける重要な側面は、案内付きのアプリ作りの進め方、数百万人の作り手候補と、これらの生成アプリの利用者へのアクセスであり、本当の製品作りに必要だと考えられる効率的な改良の過程を提供するものである。そのため、単にアプリを作り動かすだけでなく、Pi App Studioは、Piの仕組みの他の既存要素とともに、実際に動くオンライン製品の作成を可能にする。

案内付きの進め方が必要な理由は、誰もが製品を作る専門知識を持っているわけではないというPiの洞察に基づく。誰もが製品を作れるようにするには、技術的な参入障壁を解くだけでは不十分であり、それは問題の半分にすぎない。AIの台頭により、アプリ作りにおける制約は、技術力から創造性と流通へ、すなわち何を作り、どこへ公開するかへ移ってきた。

案内付きの進め方は、普通の人が、自らの分野の知識、専門性、才能を引き出し組み合わせて、他の人の役に立つ本当の製品にするために不可欠である。たとえで説明すると、絵を学んだことのない人に白い画布と筆を与えても、必要な道具はあっても、よい絵は描けない場合がある。その人独自の視点と創造性を取り入れた美しい絵を生むには、その人の作品作りに必要な構造を提供する、教育的で案内付きの進め方が必要である。

新しい製品には、試して意見を提供する利用者が必要であり、それにより特徴と事業の形をさらに改良し改善して、製品が持続可能であることを確実にできる。それこそが、Pi Networkの既存の社会的なネットワークと仕組みの要素が、アプリの作り手に提供できるものである。アプリの作り手は、既存のパイオニアから製品への現実の意見を得ることができ、それにより製品を改善し、Pi Ad Network、.pi Domains、Pi Walletなどの現在のPi製品の助けを受けて、Piでの事業の形を作ることができる。逆に、Piの仕組みは、作り手による規模の大きなアプリ作り、有用性の拡大、コミュニティの関わりから利益を得る。

このAIの取り組みの意義は3つあるとされている。

  • 世界のAIアプリ層への貢献である。Pi Networkは、世界の最近のAI基盤の進展の上に案内付きアプリ作りの進め方で革新し、Piコミュニティの群衆の創造性と、Piの社会的なネットワークの流通経路を生かす
  • ブロックチェーンを使い、人間知性とAIが持続可能に共存する経済の形を探る実験である。これは将来のAI時代に解くべき不可欠な世界的な問題である
  • 技術を持たないパイオニアが、それぞれの専門性を使い、AIとブロックチェーンを使って革新し、アプリを作り、仕組みの有用性を発展させる、草の根の力を規模拡大すること

これにより、Web2時代にアプリを作るのに要した技術コストより安く、分散した形で、より幅広い人々によるアプリ作りの改良と試みが増える。

AIをPi Networkの道具と集団的な資源と組み合わせることで、Pi App Studioは、人々が自らの知識を、他の人が使い利益を得られる現実のアプリへ変える助けとなる位置にある。

この日公開された版には、2つの選択肢が含まれる。1つ目は、作り手の分野知識と専門性を生かして生成AIチャットボットを磨き、特定の話題についての利用者の質問によりよく答え、利用者体験を調整できるよう、AIにより訓練され自動化された、話題特化型チャットボットをパイオニアが作れる進め方である。一般的なチャットボットも答えは提供できるが、個々の作り手の分野の専門性と創造性を生かした磨かれたAIチャットボットは、より合わせ込んだ答えと多様な利用者体験を提供でき、従来のチャットボットの画面を超えて広がる可能性もある。質疑応答のやり取りが常に「チャットボット」の形でなければならない理由はなく、段階案内のウィザード、対話式クイズ、推薦の仕組み、あるいはマジック8ボールのような遊び心のある形でもあり得ると述べられている。さらに、技術やAIに詳しい層を超えた大多数の一般利用者は、日常の情報の必要のために一般的な生成AIチャットボットをまだ頼りにしていない。大衆への普及を加速し、人間の生産性を高めるには、個々の作り手の専門性と創造性を注ぎ込んだ、より対象を絞った話題特化型AIアプリが、より直感的で効果的な入り口となり、より広い人々のAIへの関わりを促し得る。

2つ目の選択肢はベータ版の開かれた土台であり、パイオニアがコードを書く必要なく、すでに考えているあらゆる種類のアプリを作れるようにするものである。パイオニアは、コードではなく人間の言語を使って、作りたいアプリを作り所有できる。まだベータ版であるため、アクセスが限られる場合があり、利用者体験もまだ磨かれている最中であると注意されている。

現在の土台の上に作られる進め方が増えれば、より多くの種類のアプリ作りを案内できるようになる。

作り手のチャットボット、その他の種類のアプリ、カスタムアプリが完成すると、Pi App Studioは、AIを使ってアプリをクラウドサーバーへ自動的に配置し、自らのアプリをPiの仕組みへ公開する助けとなる。利用者の意見に基づき、作り手は、パイオニアに何が響くかを繰り返し判断し、作成の流れと似た過程でアプリに変更を加え、再配置してコミュニティへ再公開する。これらすべてを、コードを書くことなくPi App Studioを通じて行える。

他の製品と同様に利用者の参加と関わりを増やすため、Pi App Studioの作り手は、Fireside ForumやPi ChatsといったPiの他の製品も生かし、自らのアプリをより広いパイオニアコミュニティとつなげることができる。Piでの事業の形を作るために、作り手は後に、Piアプリの所有者が現在収益を上げているPi Ad Networkを利用でき、現在はアプリへのアクセスのしやすさのために、.pi Domainの入札もできる。

本人確認を終えた数千万人のパイオニアがPi暗号通貨を使い所有していることなど、Pi Networkの独自の強みが、アプリの作り手に質、成長、正確さを優先する動機を与えている。アプリの出来がよいほど、人が使う可能性が高くなる。

Pi App Studioを通じてアプリを作ることは、自らの知識と考えを中心に築かれた事業と製品を所有し運営できることを意味し、それはAIの利用により可能となり、Piのブロックチェーンの仕組みに支えられていると述べられている。

Ecosystem Directory Staking：Piを使ってPiアプリと有用性を支えること

Ecosystem Directory Stakingは、新しい土台レベルの有用性であり、パイオニアと事業者が、Ecosystem InterfaceにおけるPiアプリと有用性の順位を積極的に支え広める、分散した方法を導入するものである。Pi Browserを通じて利用でき、6月28日から展開が始まるこの機能により、パイオニアと事業者は、メインネットブロックチェーン上で、自ら選んだアプリのためにPiをステークでき、そのアプリの仕組み内での順位を直接押し上げる。ステーキングにおけるPiの有用性に加え、この機能は、より質が高く、意味のあるコミュニティの関わりを提供するアプリへ、より大きな露出を提供することも目指している。

2025年6月29日の更新として、ステーキングは、Ecosystem Interfaceで使い楽しんでいるアプリを、パイオニアと事業者が支える任意の方法であると述べられている。このステーキング機能を通じて、ネットワークが特定のPiアプリを他のアプリより推すことは意味をなさないため、プロトコル（通信や処理の決まり）の水準ではPiの報酬はない。特定のPiアプリやサービスの第三者開発者が、パイオニアに自らのアプリやサービスのためにPiをステークしてもらい、仕組み内での順位を上げてもらうために、アプリの特徴と質、利用者体験、アプリ内報酬、宣伝など、何らかの誘因を提供したいかどうかは、その開発者次第である。ステークした元の量は、ステーク期間が終わると利用者へ返される。

戦略的には、この仕組みは、Piの集団的な注目という資源を使う土台レベルの有用性であり、Piコミュニティの群衆の力でアプリと有用性を支えるだけでなく、硬直したアルゴリズムが情報の孤立を生むか、広告企業に大きく支配される、典型的なWeb2のアプリ順位付けの仕組みとは一線を画すものである。この機能は、質を高め、Pi Network全体で影響力を分散させるよう設計された循環を促す。

第三者のOnramperとオンランプサービスの連携

Pi Walletは現在、Onramperと連携している。Onramperは第三者の、KYB（事業者確認）を終えたオンランプ（法定通貨などから暗号資産へ替える入口）を取りまとめる事業者であり、パイオニア向けのオンランプサービスを簡素化するものである。パイオニアは、Pi Walletを通じてOnramperへアクセスし、地域での利用可否や他の制限を条件として、自ら好むKYB適合のオンランプサービスを選べる。この連携は、より多くのパイオニアに、メインネットの仕組みへ参加する簡素化された方法を提供する。利用のしやすさは来週にかけて段階的に広げられる。

Nodeの更新：Node Version 0.5.2とNodeランキングページ

Node Version 0.5.2が公開され、複数の重要な更新が含まれる。

  • アプリの名前がPi Desktopへ変更され、Pi NodeとPi採掘アプリの両方を含むようになった。この変更により、アプリはより一般的で正確となり、必ずしもNodeに関連しない現在の将来のデスクトップ上での連携にも開かれる。たとえば、大きなパソコン画面でPi App Studioへアクセスすることなどである（Pi DesktopでApp Studioを開くには、Pi AppタブのΞハンバーガーメニューでPi Utilitiesを選ぶ）
  • 安全性が全体として改善された
  • パイオニアは、Nodeランキングページで自らのNodeを識別するため、Nodeの項目で公開鍵を直接見ることができる。この公開鍵は、利用者のNodeを確認し識別するために使える
  • デスクトップアプリのウィンドウの大きさを変更できるようになり、Pi App Studioなどの一部の機能での使い勝手が改善された

Pi Blockexplorerの新しいNodeランキングページは、信頼性、利用可能性、開いているポート、活発な日数の合計、CPU性能などの主要な性能指標に基づいて、上位5,000のPi Nodeを表示する。順位は、ネットワークからの最新のデータを反映するため、24時間ごとに更新される。このページは、Piの仕組みに貢献する、最も安定し性能の高いノードを目立たせる助けとなる。

メインネット移行とKYCの更新：500,000人を超える追加のパイオニアの障害を取り除くこと

メインネット移行とKYCについての最近の更新により、より多くのパイオニアが移行の対象となれるようになった。これらの更新により、以前は進めなかった500,000人を超える追加のパイオニアの障害が取り除かれた。これは、オープンネットワーク開始以降に300万人を超えるパイオニアを移行させた通常の移行の流れに加わるものである。

1つのKYC更新は、さらなる確認が必要な特有の課題がある特定地域のパイオニアについて、Tentative KYC（仮の本人確認）の状態から最終的なKYC状態へ到達し、メインネット移行の過程を続けられるよう、障害を取り除く助けとなった。

移行の過程は、他のブロックチェーンの通信とは分けた、専用のブロックチェーンAPIサーバーを持つことでも改善された。これにより、移行の安定性と処理量の改善が助けられる。

パイオニアは、移行が起こる前に、具体的な行動を完了する必要がある場合がある。正確な時期は、各個人がそれらの手順をいつ終えるかによるが、以前は移行を妨げていたシステム上の制限によって、もはや制限されることはない。

.pi Domains Auctionの延長

以前の記事で論じられたとおり、.pi Domainsは、機能するWeb3の識別子、すなわちPiで動くアプリ、サービス、店舗の拠り所となることが意図されている。はるかに多くのパイオニアが自らのアプリを作り運営できるようになるPi App Studioが公開されたため、そのアプリで使うドメインが必要になることから、.pi Domains Auctionの期限は2025年9月30日まで延長され、パイオニアが革新し機能するアプリを作り、自らのアプリのために望む.pi Domainsへ入札する時間をより多く提供する。
