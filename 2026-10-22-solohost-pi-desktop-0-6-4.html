Pi Desktop 0.6.4：ルーター設定なしで遠隔接続、SoloHostの保護も強化

公開日：2026年10月22日

カテゴリ：開発者向け、更新情報

元の英語タイトル：Pi Desktop Version 0.6.4: Easier Remote Access and Stronger SoloHost App Protections

原文（英語）

このページは、Pi Network公式ブログの記事を平たい日本語で要約したものである。全文の翻訳ではない。正確な表現は原文（英語）を確認してほしい。

Pi Desktopのバージョン0.6.4は、SoloHostの遠隔接続を更新し、遠隔アクセスをより簡単で安全なものにした。これにより、パイオニア（Piの利用者）は家庭のルーターを設定することなく、Pi Browserを通じて、自分の場所で運用しているアプリにアクセスできるようになる。この公開には、SoloHostのアプリに対するより強い保護と、細かな画面の改善も含まれる。

SoloHostのアプリへの、より簡単で安全な遠隔アクセス

Pi Desktop 0.6.4により、SoloHostのアプリへの遠隔アクセスは大幅に容易になる。SoloHostは開始以来、パイオニアのコンピュータが自身のサーバーとして働くことを可能にしており、パイオニアはPi Browserの中のモバイルSoloHostアプリから、デスクトップ上で動いているAIエージェントのような対応アプリに遠隔でアクセスできる。

以前は、この遠隔接続の設定には家庭のルーターの変更が必要であり、特定のネットワークでは機能しない場合もあった。

Pi Desktop 0.6.4では、それらのルーターの変更は不要になる。Pi Desktopは今や、利用者が自宅ネットワークのポート（通信の入口）を開けることを求めずに接続を確立する。これにより、SoloHostのアプリへの遠隔アクセスにおける大きな技術的障壁が取り除かれ、自分で運用するアプリがより便利で身近なものになる。

遠隔アクセスは、パイオニアが任意で有効にするものであることに変わりはない。以前に遠隔アクセスを設定したパイオニアは、遠隔アクセスの画面で「Reconnect（再接続）」を選ぶだけで、新しい接続に切り替えることができる。

動かすアプリに対する保護の強化

遠隔アクセスの簡素化と並んで、Pi Desktop 0.6.4は、SoloHostのアプリを動かすコンピュータに対する保護をさらに提供する。

この仕組みは今や、各アプリが自身のファイルとネットワークにのみアクセスできることを検証するための技術的な支援を提供し、アプリが利用者のコンピュータの他の部分、Pi Node、あるいは別のアプリのデータにアクセスする可能性のリスクを下げる。この確認は、インストールの前と、個々のアプリが起動するたびに行われる。

同じ確認は、アプリが初めて公開される際にも実行され、これらの確認に合格しないアプリがSoloHostのカタログに入ることを見つけて防ぐ手助けをする。これにより、アプリの公開から、インストール、起動まで、複数の段階でこれらのリスクを和らげる役割を果たす。パイオニアはそれでも、各アプリやパッケージを自分で評価し、自己責任でインストールすべきである。

この公開には、Pi Nodeのポート開放の画面の更新を含む、細かな画面の改善も含まれる。

これらの変更を合わせると、より身近な自分での運用の体験が支えられる。つまり、自分のコンピュータで動いているアプリへのアクセスが容易になり、そのアプリが何にアクセスできるかについての保護が強まるということである。

Pi MainnetはProtocol 28へのアップグレードに成功

Pi Mainnetは、2026年10月16日にProtocol 28へのアップグレードも無事に完了した。このアップグレードは、ネットワークが取引データの遅れをどう扱うかを改善し、開発者にとってスマートコントラクト（契約条件を自動で実行するプログラム）の保守を容易にする。内容には、スマートコントラクトのグループを一度にアップグレードすることや、アプリの発展に合わせて保存されたデータへの変更をより安全に行うことが含まれる。
