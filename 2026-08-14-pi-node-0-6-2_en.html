Release of Pi Node Version 0.6.2 & SoloHost Updates

Published: August 14, 2026

Categories: developer, update

Original article

This page is a plain-English summary of an article from the official Pi Network blog. It is not a full translation. Difficult words and expressions are explained in simple words. For the exact wording, see the original article.

Version 0.6.2 of Pi Node (the software you run on a computer to support the Pi network) has been released. It includes improvements to SoloHost, Node connections, and the ease of use of Pi Desktop.

In addition, Pi has successfully completed a test of distributed computing (splitting computing work among several computers) through a SoloHost app. Through this, the role of Pi Nodes expands beyond supporting the Pi blockchain (a system that manages transaction records in a distributed way).

Release of Pi Node 0.6.2

Version 0.6.2 includes the following updates.

  • Automatic port setup with UPnP and a new port checker: it now supports UPnP (a system where a compatible router automatically opens the entrance for communication) and helps open the ports needed for Node connections automatically. Until now, Node operators and users of SoloHost apps, such as local AI agents (AI assistants that run on your own computer), had to set their router ports by hand, which was technically difficult for some people. Together with the new port-checking system, setting up connections between local devices, such as between a Pioneer's mobile device and an app running on a Node, becomes easier
  • Support for unlisted SoloHost apps: Pioneers can now choose, at their own judgment, to run apps on SoloHost that have not yet been publicly listed. Even while an app is not yet public, developers can test and check reachability more easily
  • State management for SoloHost apps: developers can now manage SoloHost apps in three states: draft, unlisted, and listed. They can control in more detail how an app is shown and staged before and after publication
  • Fix to a SoloHost app state display problem: there was a display problem where, after starting a SoloHost app, moving to another screen in Pi Desktop and coming back, the app's state was sometimes not shown correctly. This has been fixed. The screen now follows the app's current state and reflects it correctly
  • Correct movement to the app tab: after a SoloHost app finishes installing and starts running, Pi Desktop now switches correctly to the app tab. It no longer switches partway through startup, as before
  • Featured SoloHost apps added: in addition to the unlisted distributed computing app described in detail below, which finished its test, two SoloHost apps, mcp-atlassian and OpenClaw, will be added to the featured section, alongside Hermes

With these updates, the Node and SoloHost experience becomes simpler, more flexible, and more reliable. By making local connections easier, improving app management, and supporting more flexible app development and testing, 0.6.2 continues to strengthen the foundation for applications that run on Pi Nodes, including AI agents and other locally running services.

The distributed computing test through a SoloHost app

Together with the release of the new Node 0.6.2, Pi completed the first test of the distributed computing function through SoloHost, together with 5 volunteer Node operators.

The devices of all 5 participants successfully completed computing tasks (computing jobs) that were sent automatically through the SoloHost app. In this test, the full flow through real devices was confirmed: connecting to Pi's coordinator, receiving and processing computing jobs, and sending back the results.

SoloHost is an open, permissionless framework (a basic structure anyone can join without approval) on Pi Desktop, released in beta (a trial version before the official release) at Pi2Day 2026. Developers can build and list self-run apps and tools for Nodes here, and Pioneers can run them on their own computers. While the first release supported locally running apps such as AI agents, Pi has continued work to enable distributed computing apps that use spare Node resources.

This distributed computing effort is built on an earlier proof-of-concept project (a trial to check whether an idea actually works), which explored whether Pi's worldwide Node network of more than 420,000 nodes can support decentralized AI training and computing tasks. Through SoloHost, the aim is to complete it as a real app that further automates the function, widens its scale, and provides a practical level of usefulness for third-party clients. Participating Nodes can receive rewards in Pi from third-party clients, in return for turning spare computing power into a resource for practical uses.

By helping suitable applications use spare Node resources, SoloHost and the apps listed there can turn Pi Nodes into a practical computing layer for AI-related applications and other work that needs a lot of computing. At the same time, Pioneers gain a way to contribute directly to, and benefit from, these new production systems through the computers they already run.
