Piハッカソン2025が始まる、賞金総額は最大160,000 Pi

公開日：2025年8月15日

カテゴリ：お知らせ、ハッカソン関連

元の英語タイトル：Pi Hackathon 2025: Enhance Pi Utility in the Open Network Era

原文（英語）

このページは、Pi Network公式ブログの記事を平たい日本語で要約したものである。全文の翻訳ではない。正確な表現は原文（英語）を確認してほしい。

Pi Networkは、オープンネットワーク開始後、仕組みの中で初めてのハッカソン（短期間に集中して開発を競う催し）となるPi Hackathon 2025を開始した。開発者に、Piを使って現実の場面で役立つPiアプリを作って公開し、仕組みを形作ることを求めるもので、賞金総額最大160,000 Piをかけて競う。

オープンネットワークの外部接続により、Piをこれまで採掘したことがない人を含む日常の利用者に向けて、実際の使い道と有用性をもたらす実用的なアプリを通じて、Piの現在の有用性をさらに広げる機会が生まれている。

Pi2Day 2025で生まれたアプリ作りの勢いを受けて、このハッカソンは、世界中でPiをより使いやすく、身近なものにする道具、アプリ、体験を開発者に作るよう促すものである。

課題：Piの有用性を高めるアプリを作ること

課題は、人々が仕組みに関わり、参加できるようにすることでPiの有用性を高めるPiアプリを作ることである。テーマは幅広く自由であり、創造性を広く招く形になっている。アプリはどのような使い道に焦点を当ててもよいが、メインネット掲載要件に従い、Piコミュニティに本当の有用性をもたらす必要がある。

開発者には、次のことが勧められている。

  • 利用者の本当の必要に基づいて工夫し、創造的であること
  • Pi Open Source（PiOS、Piのオープンソースの仕組み）を使ったオープンソースのプロジェクトを作り、コミュニティの貢献を生かすこと
  • Pi App StudioとBrainstormアプリを出発点として、初期の考えを本格的なアプリへ変えること
  • コーディング支援を含むAI技術を使い、アプリの開発と改良を支えること

賞金

受賞チームには、次の賞金が贈られる。

  • 1位：75,000 Pi
  • 2位：45,000 Pi
  • 3位：15,000 Pi
  • 佳作（最大5チーム）：各5,000 Pi

参加方法

ハッカソンに参加するには、次のことを行う。

  • 公式のHackathon Registration Formで登録し、最新情報を受け取るためのメールリストに参加すること
  • Pi App Studio、Developer Portal（開発者向けの登録・管理画面）、共有資料を使って、チームで作り、協力すること

日程

  • 8月15日 登録とチーム作りの開始：参加者はハッカソンに登録し、チームを作るか参加し始めることができる
  • 8月21日 ハッカソン正式開始：ハッカソンの正式な開始である
  • 9月19日 中間確認：チームには中間確認フォームの提出が勧められる。提出したプロジェクトは、追加の助言、Piコミュニティへの紹介の機会、最終審査前の意見を受けられる場合がある
  • 10月15日 最終提出期限：Developer Portalでのアプリ掲載、デモ動画、提出フォームを含む、すべての最終提出が期限となる

チームの人数

チームの人数に上限はない。開発者には協力し、焦点を絞ったチームを作り、より少ないが質の高いアプリを作ることが勧められている。チームは10月15日までに、最終提出フォームで最終的なチームメンバーの一覧を提出しなければならない。また、賞金を受け取る資格を得るには、すべてのチームメンバーがPiのKYC（本人確認）を通過する必要がある。

提出の要件

アプリがPi Hackathon 2025の有効な提出として認められるには、次の2つの手順を完了しなければならない。

  • デモ動画を添えて、Hackathon Submission Google Formを提出すること（期限が近づいたら共有される）
  • Pi Developer Portalでアプリを提出すること

完全な提出として数えられるには、両方の手順が必要である。詳しい内容とリンクは、期限が近づくにつれて参加者に共有される。

1. 推奨：中間提出（2025年9月19日まで）

進み具合を確認し支援を提供するため、チームには中間確認を行うことが勧められている。最終評価には必須ではないが、この手順を完了すると、追加の助言と意見を受けられる資格や、提出日が近づく中で早い段階で利用者の注目とコミュニティへの紹介を得られる可能性がある。

中間提出では、次の内容が求められる場合がある。

  • アプリの名前とURL
  • 開発中のアプリのプレビュー画像
  • 予定する特徴と機能をまとめた、短い開発計画の文章

提出フォームと具体的な要件は、提出期限の前に、登録したすべての参加者に直接配られる。

2. 最終提出フォームとデモ動画

最終提出フォームは、期限の前に、登録したすべての参加者に直接配られる。

各チームは、アプリの最終版を紹介するデモ動画を作らなければならない。この動画はYouTubeまたは他の動画共有サービスで公開し、そのリンクを提出フォームに含めなければならない。

デモ動画では、次の内容を取り上げることとされている。

  • アプリとその目的を説明する短い紹介
  • アプリの機能と画面の使い方の実演
  • 対象とする利用者の説明
  • アプリが取り組む問題や必要
  • Piが利用者体験にどう組み込まれているか（支払い、ログインなど）

デモは簡潔で分かりやすく、全体で3分以内にすることとされている。

3. Developer Portalでの最終アプリ提出

Developer Portalを通じてアプリを提出するには、次の手順を完了する。

I. ハッカソンコードを入力する。Pi Browserを開いてDeveloper Portalへ行き、メインの「Develop」ページで「Hackathon」ボタンを押す。ハッカソンコード「hackathon25」を入力し、「Join」を押す。これにより、Developer Portalのアカウントがハッカソン参加者として記録される。

II. メインネットアプリを作り登録する。すでに作成中のメインネットアプリがある場合は、ハッカソンに提出したいアプリを選び、Developer Portal Checklistをできるだけ多く完了する。新しく始める場合は、Developer Portalで「New App」を押し、通常のアプリ作成の流れに従う。アプリの種類として「Mainnet」を選ぶ。なお、メインネットアプリの登録には、テストネット版との連携が引き続き必要である。Developer Portal Checklistをできるだけ多く完了する。

III. ハッカソンへアプリを提出する。対象となるハッカソン期間中にコードを入力すると、Checklistのステップ10（「Add a PiNet subdomain」のステップ）に到達した時点で、新しい「Submit to Hackathon」ボタンが現れる。「Submit to Hackathon」を押すと、アプリは自動的にハッカソンの区分へ提出される。提出されたアプリは、数週間以内に、Pi BrowserのPi AppsタブにあるHackathon Submissionsページに掲載される。

IV. アプリのウォレットと仕組みの設定。現時点では、ハッカソン提出にウォレットの設定は必要ない。チームは催しの後にこの手順を完了してもよく、特に受賞者に選ばれた場合や、正式な仕組みへの掲載へ進む場合に行う。

V. アプリの資格。各利用者は、ハッカソンに最大2つまでメインネットアプリを提出できる。アプリは、求められるすべてのMainnet Listing Guidelinesに従い、独自のもので、Piの有用性に焦点を当てたものでなければならない。

4. アプリの審査基準

すべてのアプリは、次の基準に基づいて審査される。

  • Mainnet Listing Guidelinesへの適合
  • Piの有用性と、コミュニティ全体の必要との適合
  • 技術的な完成度と革新性
  • UI/UX（画面と使い勝手）、使いやすさ、操作のしやすさ
  • Piメインネットブロックチェーン上での長期的な有用性
  • 独自性と特徴のある使い道

アプリはさらに、次の条件も満たさなければならない。

  • 英語の名前があること
  • 商標の指針に従ったロゴがあること
  • 英語で正確な説明があること
  • アプリの画面と使い勝手を示すプレビュー／デモ画像を含むこと
  • PiNetと連携していること
  • プライバシーポリシーを含むこと

資料

  • Developer Onboarding Guide：Piの仕組みで新しい開発者として準備するために必要な手順を詳しく述べたもの。初めてPiで開発する場合はここから始める
  • Getting Started Checklist：開発を始めるために必要な手順の手早い案内
  • Pi Platform Github Repository：Pi SDKとAPIを組み込むために必要なすべての情報をまとめた、Piの開発者向け文書
  • Pi Demo App Repository：アプリの設計図として、Piのデモアプリのコードを確認したり複製したりできるもの。試すには、Pi Browser内で「demo.pi」へ移動する
  • PiOS：Pi Open Sourceのソフトウェアライセンスとその使い方について学ぶもの
  • SDK Workshop：Pi SDKの使い方についての発表を見るもの
  • Product Workshop：ハッカソン参加者向けに合わせた、Pi上で作るPiアプリの製品設計の案内を見るもの
  • Mainnet Listing Guidelines：メインネットアプリの基準について学ぶもの
  • PiNet：PiNet URLの設定方法の説明
  • Pi App Studio：Pi App Studioの使い方についてのデモ動画を見るもの

BrainstormアプリとPi App Studio

参加者は、Pi Browser上のBrainstormアプリを使い、試作品を共有し、他の人とつながり、Piコミュニティ内での認知を高めることができる。

Pi App StudioまたはDeveloper Portalを使ってアプリの試作品を作った場合は、それをBrainstorm上のプロジェクト掲載へ直接つなげることができる。これにより、考えを紹介し、早い段階で意見を集め、ハッカソンに向けたチームメンバーや協力者候補を見つける助けとなる。

アプリをBrainstormへつなげるには、次の手順を行う。

  • Pi BrowserからBrainstormアプリを開く
  • 下部のナビゲーションバーで「Propose」ボタンを押す
  • ページの説明に従い、プロジェクト名と短い要約を入力する
  • 提出後、プロジェクトページの下部まで移動し、「Link this project with an Application on the Developer Portal」を押す
  • Pi App StudioまたはDeveloper Portalで既に作ったアプリの中から選べるようになる

つなげると、プロジェクトは他のBrainstorm利用者に見えるようになり、より多くのパイオニアが考えを見て、関心を持ち、関わることができるようになる。

開発者への呼びかけ

Pi Hackathon 2025は、開発者が、Piの有用性とコミュニティ参加を促す現実のアプリを作ることで、Piの仕組みに意味のある貢献をする機会である。経験豊富な開発者でも、始めたばかりでも、影響のあるものを作り、他の人と協力し、考えを世界中のPiコミュニティに示す機会である。

ネットワークは、参加者がこの催しにもたらす創造性、革新性、熱意を受け入れる準備ができていると述べられている。
