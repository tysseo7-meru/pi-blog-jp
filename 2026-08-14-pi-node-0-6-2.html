Pi Node 0.6.2を公開 ― SoloHostの改善と分散コンピューティングのテスト完了

公開日：2026年8月14日

カテゴリ：開発者向け、更新情報

元の英語タイトル：Release of Pi Node Version 0.6.2 & SoloHost Updates

原文（英語）

このページは、Pi Network公式ブログの記事を平たい日本語で要約したものである。全文の翻訳ではない。正確な表現は原文（英語）を確認してほしい。

Pi Node（Piのネットワークを支えるためにパソコンで動かすソフト）のバージョン0.6.2が公開された。SoloHost、Nodeの接続、Pi Desktopの使い勝手に改善が入っている。

あわせてPiは、SoloHostアプリを通じた分散コンピューティング（計算の仕事を複数のパソコンに分けて処理すること）のテストを無事に完了した。これにより、Pi Nodeの役割はPiブロックチェーン（取引記録を分散して管理する仕組み）を支えること以外にも広がっていく。

Pi Node 0.6.2の公開

バージョン0.6.2には次の更新が含まれる。

  • UPnPによる自動ポート設定と新しいポートチェッカー：UPnP（対応ルーターが自動で通信の入口を開く仕組み）に対応し、Node接続に必要なポートを自動で開けるよう助ける。これまではNodeの運営者や、ローカルAIエージェント（自分のパソコン上で動くAIの助手）のようなSoloHostアプリの利用者が、手作業でルーターのポートを設定する必要があり、一部の人には技術的に難しかった。新しいポート確認用の仕組みとあわせて、パイオニアの携帯端末とNode上で動くアプリの間のような、ローカル機器同士の接続の設定が簡単になる
  • 未掲載のSoloHostアプリへの対応：パイオニアが、SoloHostにまだ公開掲載されていないアプリを、自分の判断で選んで動かせるようになった。アプリがまだ公開されていない段階でも、開発者がテストや到達確認をしやすくなる
  • SoloHostアプリの状態管理：開発者がSoloHostアプリを、下書き（ドラフト）、未掲載、掲載済みの3つの状態で管理できるようになった。公開前後の見せ方や段階を、より細かく制御できる
  • SoloHostアプリの状態表示の不具合修正：SoloHostアプリを起動した後、Pi Desktop内の別の画面に移動して戻ると、アプリの状態が正しく表示されないことがあった表示上の問題を直した。画面がアプリの現在の状態を追い、正しく反映するよう改善した
  • アプリタブへの正しい移動：SoloHostアプリのインストールが終わって動き始めた後に、Pi Desktopがアプリタブへ正しく切り替わるようになった。以前のように起動の途中で切り替わることはない
  • 注目のSoloHostアプリの追加：下で詳しく述べる分散コンピューティング用の未掲載アプリがテストを終えたほか、mcp-atlassianとOpenClawの2つのSoloHostアプリが、Hermesと並んで注目（featured）欄に追加される

これらの更新により、NodeとSoloHostの体験はより簡単で、柔軟で、信頼できるものになる。ローカル接続を簡単にし、アプリ管理を改善し、より柔軟なアプリ開発とテストを支えることで、0.6.2は、AIエージェントやその他のローカルで動くサービスを含め、Pi Node上で動くアプリケーションの土台を強くし続ける。

SoloHostアプリを通じた分散コンピューティングのテスト

新しいNode 0.6.2の公開とあわせて、PiはSoloHostを通じた分散コンピューティング機能の最初のテストを、ボランティアのNode運営者5人とともに完了した。

5人の参加者全員の機器が、SoloHostアプリを通じて自動で送られた計算タスク（計算の仕事）を無事に完了した。このテストでは、Piのコーディネーター（調整役）への接続、計算ジョブの受け取りと処理、結果の返信まで、実際の機器を通じた一連の流れが確認された。

SoloHostは、Pi2Day 2026にベータ版（正式版前の試用版）として公開された、Pi Desktop上の開かれた、許可不要の枠組み（フレームワーク）である。開発者はここで、自分で運営するアプリやNode用の道具を作って掲載でき、パイオニアはそれを自分のパソコンで動かせる。最初の公開では、AIエージェントのようなローカルで動くアプリに対応していた一方、Piは、空いているNodeの資源を使う分散コンピューティングのアプリを可能にする取り組みを続けてきた。

この分散コンピューティングの取り組みは、420,000を超えるPiの世界中のNodeネットワークが、分散型のAI学習や計算タスクを支えられるかを探った、以前の概念実証（アイデアが実際に動くか確かめる試み）のプロジェクトを土台にしている。SoloHostを通じて、その機能をさらに自動化し、規模を広げ、第三者の依頼者（クライアント）に実際に役立つ水準の実用性を提供することを目指す、本物のアプリとして完成させていく。参加するNodeは、空いている計算能力を実際的用途の資源に変える見返りとして、第三者の依頼者からPiで報酬を受け取れる。

適したアプリケーションが空いているNode資源を使えるよう助けることで、SoloHostとそこに掲載されるアプリは、Pi Nodeを、AI関連のアプリケーションやその他の計算量の多い仕事のための実用的な計算の層（レイヤー）に変えることができる。同時に、パイオニアには、自分がすでに動かしているパソコンを通じて、こうした新しい生産の仕組みに直接貢献し、利益を得る方法が生まれる。
