Pi Network Venturesの最初の投資先はOpenMind

公開日：2025年10月29日

カテゴリ：お知らせ

元の英語タイトル：Pi Network Ventures Announces First Investment in OpenMind

原文（英語）

このページは、Pi Network公式ブログの記事を平たい日本語で要約したものである。全文の翻訳ではない。正確な表現は原文（英語）を確認してほしい。

Pi Network Venturesは、OpenMindへの最初の投資を行った。OpenMindは、ロボットが考え、学び、協力し合うためのオペレーティングシステム（基本ソフト）とオープンソースのプロトコル（決まり）を作る会社であり、「ロボット版Android」のようである。

OpenMindへのこの投資は、Pi NetworkとPi Network Venturesの両方の主な狙いに沿う。Pi Networkは、ブロックチェーンとその背後にある資源を使い、現実の問題を解くことに努めている。Pi Network Venturesは、世界の生産をより多くPiの上に取り込み、Piの使い道を増やすために働いている。

OpenMindの技術は、ロボットが分散型の仕組みの中で協力し、共に学べるようにする、共有された知能の層を作る。これは、分散型の基盤が開かれた革新と公平な参加を支える、ブロックチェーンとAIの将来というPiの考えを補う。

この投資を超えて、Pi NetworkとOpenMindは協力し、実証実験を完了した。そこでは、志願したPi Node運用者がOpenMindのために画像認識のAIモデルを動かし、Pi Node運用者が外部の組織のために計算を動かせることが証明された。OpenMindのAIモデルがPi Nodeの基盤上で動くこの初期の実験は、分散型のAI学習と計算の仕事を支える、Piの世界中のノード網の能力を探るものである。これは、Piの台帳を守ることに加えた、もう一つのPi Nodeの使い道である。これはまた、ネットワーク全体の資源、すなわち35万を超える稼働中のノードの計算力に依拠する、基盤レベルの使い道でもある。

使われていない計算力を生産的な仕事へ変えることで、この取り組みは、（1）AI製品が、ノードを動かす人へPiで支払うことで、Pi Nodeから計算の需要を取り寄せ満たせるようにし、（2）Pi Nodeを動かす人が、ノードのマイニング報酬とは別に、追加のノードの使い道からPiを得ることを選べるようにする。このPi Nodeの使い道は、これらの計算とAIモデル学習の貢献を通じて、PiをAI経済へさらに組み込む助けとなりうる。

OpenMindとPi Network Venturesの狙いとの戦略的な適合

OpenMindは、ロボットと知的な仕組みが、自らの環境や互いと、安全に、単一の提供元の仕組みに依存せずに関われるようにする基盤を作っている。ハードウェアに依存しないOM1オペレーティングシステムは、知的な機械を現実の文脈へ組み込むことを支える。新しく導入されたFABRICプロトコルにより、機械は身元を確認し、文脈を共有し、物理的とデジタルの環境を越えて連携できる。OpenMindについては、リンク先で詳しく知ることができる。

OpenMindへの投資は、AI中心の世界におけるブロックチェーンというPi Networkのより広い考えに向けて取り組む、潜在的な機会を提供する。

Pi Network VenturesがOpenMindの資金調達の回に参加したことは、Pi Networkの方向性に沿う、ブロックチェーンと技術分野全般における強い新興企業や事業を支えるという、その約束を映している。これは、その3つの中心的な投資の狙いを補う。

  • Piの使い道を増やすこと
  • 世界の生産をより多くPi Networkの上に可能にすること
  • Piを現実の利用場面へ持ち込むこと

AI中心の世界におけるブロックチェーンについて、Pi Networkは、技術的な生産性、とくにAIによるものが、分配、生産、人間の労働と知能の役割についての問いを生むと認識している。人間に代わって行動するAIの担い手によって生産性と取引がますます行われる将来において、これらの担い手のための支払い方法の組み込みと利用のしやすさは、重要な特徴である。

これらの担い手が、現実の環境で自律的に動き、効果的に連携できるようにする基盤は、欠かせないものとなる。

OpenMindは、自律的な物流から産業の自動化まで、分野を越えた機械の協力を支える共有された知能の層を作り、相互に運用できるAIアプリの層の前進に貢献しようとしている。この層は、高性能なAI基盤と現実の生産の間に位置し、Piの見方では、その層を強くすることが、AIの恩恵が人間の参加者へ公平に届くことを確かにするために欠かせない。

OpenMindが作っている構造は、知的な仕組みを、開かれ適応できる形で大規模にするのに必要な、連携の基盤を作るための一つの道筋を示す可能性がある。今度は、そうした仕組みが、身元、アクセス、認証、支払い、動機の仕組みといった、ブロックチェーンで可能になる層の機会を作る可能性がある。これらは、Piが既存の基盤と仕組みの活動を持つ分野である。

その文脈で、Pi Network VenturesによるOpenMindへの投資は、ますますAIが中心となる世界において、現実のPiの使い道と組み合わされた技術と仕組みの環境を整えるという、より広い狙いを支える。

実証実験：分散型計算の使い道に向けて作る

Pi Node運用者がOpenMindのために計算を動かせる取り組みは、Piの世界中のノード網に分散した容量を活用し、AI学習のための分散型計算を探る初期の段階を示している。

Piの合意の仕組みは、エネルギーを効率よく使うよう設計されている。つまり、台帳を守ることだけでは、35万を超えるPiのノード網全体の計算能力をすべて必要としない（ただし、これら多くのノードによる分散という面からは恩恵を受ける）。そのため、Pi Nodeには、使われていない計算能力の大きな蓄えが残っている。この全体の計算能力は、分散型のクラウド計算といった、ノードの層の上に新しい使い道を可能にできる貴重な資源である。

AIがますます大きな計算資源を求め続ける中で、世界的なWeb3ネットワークのこの余った容量を使うことは、その需要を満たす助けとなり、Piに現実の使い道を提供できる。ノードがAIに関わる計算を行えるようにすることで、Piは仕組みの中に新しい分野の使い道と経済活動の可能性を開く。AIモデルの学習に計算力が必要な側は、追加の容量に対してノード運用者へPiで支払うことができ、従来の中央集権的な基盤より利用しやすく費用対効果の高い、分散型のクラウド計算の市場を作る。

この考えは、Piの分散型の労働のネットワークと計算の層を組み合わせることで、さらに広がる可能性がある。AIモデルの開発者は、同じ仕組みの中から、人間のフィードバックと計算力の両方を利用できる。そのことで、Piは、人々が労働に貢献し、計算を提供し、その見返りにPiを受け取る、自ら完結した環境を可能にすることを目指す。これにより、分散した参加を通じてAI開発の次の波を支える。

なお、Pi Network Venturesの投資は、世界で価値を生み、世界中でPiを使う追加の方法を提供するのに最も適していると考えられる相手に対し、より広い期間にわたって、資金と戦略的な価値の両方を提供することを意図している。投資の手順は、調達、選定、審査の手順などに関して、従来のシリコンバレーのベンチャーキャピタル（新興企業へ投資する会社）のやり方を映すことを意図しており、影響が大きく革新的な新興企業や事業を見つけ支えるために設計されている。そのことを踏まえると、Pi Network Venturesの参加は、あくまで投資として理解されるべきであり、投資先が成功するという保証ではない。ベンチャーキャピタルのやり方は、変革をもたらす新興企業と革新を支えることを求めるものであり、それは各チームの強さと実行によって左右され、潜在的な危険を上回る高い成功の上限を持つ会社に重点を置く。
