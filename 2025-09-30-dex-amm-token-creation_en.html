Pi DEX, AMM Liquidity Pools and Token Creation Features Now Live on Pi Testnet

Published: September 30, 2025

Categories: announcement, general

Original article

This page is a plain-English summary of an article from the official Pi Network blog. It is not a full translation. Difficult words and expressions are explained in simple words. For the exact wording, see the original article.

As Pi founder Dr. Chengdiao Fan announced live on stage at TOKEN2049, Pi Network introduced a set of new features to its blockchain (a shared record system). These features are released first only on Testnet (the test network), for testing only. After the test period, they will be available on Mainnet (the real, live network).

Pi DEX and AMM

DEX (a decentralized exchange, a system for trading without a central manager) and AMM (an automated market maker, a system that sets prices automatically and makes trades happen) liquidity pool (a place that gathers currency for trading) features are now available on Testnet. Developers and Pioneers (Pi users) can directly try token swaps, liquidity pools, and other decentralized finance tools. On Pi Testnet, you can keep using Test-Pi to use these features. On Mainnet, this feature is limited for now, but the Pi Wallet screen shows these options and guides users to the Testnet environment. These features are built into the base system of the Pi blockchain itself. The community can also build its own DEX and AMM screens.

With the launch of DEX, AMM, and liquidity pools on Testnet, developers and Pioneers get a real environment where they can try how decentralized finance (DeFi, finance without an intermediary such as a bank) works inside the Pi ecosystem. In this environment, each project can safely test features on Testnet before introducing them on Mainnet.

With these tools, Pioneers can also touch tokens in practice and learn. Before taking part directly in DeFi on Mainnet, where real Pi is used, they can try swaps, add or remove liquidity (funds put in for trading), and watch how a decentralized exchange works, and learn about DeFi themselves. Because these features are limited on Mainnet at present, all activity is done on Testnet, using Test-Pi and test tokens that are used only for testing. They cannot be used on Mainnet or for other purposes. In this form, users can experience and refine how they approach DeFi in the Pi ecosystem. It aims to raise financial knowledge across the whole network before people take part in DeFi on Mainnet.

Token creation

For Pi DEX and AMM to work, token creation is needed first. Developers can now create test tokens on the Pi Testnet blockchain. On Mainnet, this feature is also limited during the test period. Documentation that explains this process will be provided in the coming weeks. Test tokens can be created freely on Testnet for testing, using Test-Pi. But extra rules will apply to token creation on Mainnet. This is to align the motives of creators toward building things with real uses, as Dr. Fan said about the crypto industry in the keynote speech at TOKEN2049. These rules focus on encouraging real apps, services, and lasting products in the Pi ecosystem. They also focus on having a reasonable token supply and distribution plan.

The focus on real uses is especially important to separate these tokens from empty incentive systems, such as most memecoins (coins that spread only because they are talked about). Memecoins have shown that communities can take part widely in token systems. But because they have no real use behind them, they are unlikely to last long. Pi Network's approach to tokens focuses on linking the creation of uses to real uses at the app or system level. It aims to make sure tokens exist to power functions, not for speculation (buying and selling only in hope of a price change).

Building on Pi's base

These features support the idea of letting not only developers, but also Pioneers who are not technical and who create AI-powered apps in Pi App Studio, start their own tokens for real uses. Examples are functions inside an app, community participation, and system-level services.

Creators can start by issuing and distributing a token on Testnet first, trying liquidity pools, and checking how the token connects with their app. Other examples can include DEX and AMM systems built by the community.

Pi Network already provides the main base to support this feature. Pi's KYC system (identity verification) makes sure Pioneers are real, and ensures that distribution reaches real people. With a global community of tens of millions of verified members, developers have users for testing and for gathering opinions from the start. Ecosystem products, including Pi Wallet, .pi Domains, Pi Ad Network, and the staking feature in the ecosystem directory (a feature where you put in Pi to support an app), support real token introduction, management, and lasting business forms inside the network.

Supporting the ecosystem through usefulness and Web3

By opening DEX, AMM, and tokens on Testnet, developers can widen what Pi Network can do in a structured way, with a focus on real uses, and in a Web3 way (a decentralized internet based on blockchain). It is also a path for Pioneers to enter DeFi through a safe, step-by-step, and learning-based journey of discovery. This step strengthens the ecosystem by using the power of Web3 to increase usefulness, openness, and decentralization (spreading control instead of keeping it in one place).
