エコシステム一覧のステーキング表示を更新：Piを預けてPiアプリを応援し広める

公開日：2026年6月18日

カテゴリ：開発者向け、一般

元の英語タイトル：Ecosystem Directory Staking Visual Update: Stake Pi to Support and Promote Pi Apps and Utilities in the Ecosystem

原文（英語）

このページは、Pi Network公式ブログの記事を平たい日本語で要約したものである。全文の翻訳ではない。正確な表現は原文（英語）を確認してほしい。

Ecosystem Directory Stakingは、パイオニア（Piの利用者）や企業が、Ecosystem Interface（Piアプリの一覧画面）の中でPiアプリや道具の順位を支え、広めるための分散型の方法である。ここでのステーキング（Piを預けてアプリを応援する仕組み）とは、一定期間Piを預けることでアプリを応援する仕組みを指す。

Ecosystem Interfaceは、パイオニアがPi Browserでカテゴリ別にPiアプリを閲覧できる場所であり、メインネットアプリ、Pi App Studioアプリ、中央集権型取引所のようなサービスを含む。

パイオニアや企業は、メインネットのブロックチェーン（取引記録を分散して管理する技術）上で自分のPiをステーキングすることで、仕組みの中でアプリやサービスの順位を直接押し上げることができる。ステーキングはアプリがPiコミュニティの目に触れる機会を増やし、表示回数の増加と、利用者の流入の増加につながる可能性がある。この機能は、開発者や制作者がPiを使ってPi Networkの注目という資源を活用し、利用者を獲得するための自分で使える手段を提供する。コミュニティも、一般的なWeb2のアプリ一覧のようなコメントだけでなく、経済的な重みを持つ実際のステークを通じて、共同でアプリを評価できる。

ステーキングはもともと2025年6月に開始されたものであり、Piの軽量なプラットフォームレベルの使い道である。Pi Ad NetworkやPi Launchpadと比べて、申請や承認の手続きに多くの作業を必要とせず、開発者がPiの注目と利用者獲得の資源にアクセスするための設定と参加の手間は最小限である。

例えば、CiDi Gamesのベータ版開始から1週間も経たないうちに、そのアプリの順位は319万Piのステーキングによって自然に押し上げられ、強い露出と1週間未満で120万回を超えるゲームプレイにつながった。これは、Ecosystem Directory Stakingがコミュニティの関心を示す目に見える合図として役立つことを示す。

今週、Ecosystem Directory Stakingは更新されたデザインを公開し、利用体験のさまざまな改善が行われ、開発者、制作者、バイブコーダー（AIを使ってアプリを作る人）、パイオニアによるさらなる活用の準備が整った。アプリの順位はPi BrowserのPiAppsタブで見ることができ、今回の更新により仕組みの発見と移動がより簡単になった。

Ecosystem Directory Stakingは、AI支援ツールによってアプリを作ることが簡単になる一方で、実在の利用者に届けることが難しくなっている状況で特に役立つ。これは、バイブコーダー、開発者、制作者がPiを使って、Piの仕組みにいる6,000万人を超える活発なパイオニアに自分のアプリを発見してもらい、支えてもらい、改善してもらう方法を提供する。

注意点として、ステーキングに対するプロトコル（基盤の仕組み）レベルのPi報酬はない。これは、ネットワークが特定のPiアプリを他のアプリより推すことはしないためである。ステーキングへの動機付け、例えばアプリの機能、全体の品質、利用体験、アプリ内報酬、販促、その他の利点を提供するかどうかは、そのPiアプリやサービスの外部の開発者が決める。もとのステーキングした金額は、ステーキング期間が終了した後に利用者へ返される。
