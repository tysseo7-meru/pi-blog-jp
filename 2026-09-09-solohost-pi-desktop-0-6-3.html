Pi Desktop 0.6.3のSoloHost更新：アプリの見つけやすさ、安定性、開発者向け道具を改善する

公開日：2026年9月9日

カテゴリ：開発者向け、更新情報

元の英語タイトル：SoloHost Updates in Pi Desktop Version 0.6.3: Improved App Discovery, Reliability, and Developer Tools

原文（英語）

このページは、Pi Network公式ブログの記事を平たい日本語で要約したものである。全文の翻訳ではない。正確な表現は原文（英語）を確認してほしい。

SoloHost（自分で運用するアプリをPi Desktopから入れて動かせる仕組み）の更新が、Pi Desktopのバージョン0.6.3とあわせて出された。内容は、アプリの発見と管理の改善、アプリの安定性の改善、SoloHostアプリを作り問題を調べるための開発者向け道具の改善である。

なお、バージョン0.6.3からは、これらの公開をPi NodeバージョンではなくPi Desktopバージョンと呼ぶことになる。

Pi Desktop 0.6.3に含まれるSoloHostの更新内容

  • 実行中の人数に基づくSoloHostアプリの順位付け：コミュニティのSoloHostアプリは、今そのアプリを動かしている人の数に基づいて順位付けされるようになった。これにより、SoloHostの中で活発なコミュニティアプリが目立つようになり、パイオニア（Piの利用者）が他の人が実際に使っているアプリを見つけやすくなる
  • 新しい「My Apps」の欄：SoloHostのホーム画面に新しい「My Apps」の欄が加わり、今の利用者が公開したアプリが表示される。開発者や公開者に、自分のSoloHostアプリを見つけて管理するための専用の場所ができる
  • SoloHostアプリの準備確認（レディネス・プローブ）：準備確認はSoloHostアプリの状態を確認し、接続などの問題で時々起きる502エラー（サーバー側の応答エラーの一種）を避ける助けになる。これにより、アプリが準備できて正しく応答しているかをSoloHostがよりよく判断でき、アプリ体験の安定性が高まる
  • 問題調べのためのDocker Compose対応の改善：コマンドライン（文字で命令を入力する画面）で作業したい技術的な利用者は、インストール先のフォルダへ移動し、SoloHostの外で標準のdocker compose upとdocker compose downの命令を実行できる。これにより、コンテナ（アプリを隔離して動かす箱）の開始と停止を試し、必要なときに問題を調べる別の方法ができる
  • 新しいSoloHost開発者向け契約（コントラクト）：開発者がSoloHostアプリを作る助けになる、最初のSoloHostリポジトリ（ファイル置き場）が用意された。このリポジトリはAIエージェント（AIが自律的に作業する仕組み）が理解しやすい形になっており、AIが開発者のSoloHostアプリ作成をより効果的に助けられる
  • 不具合の修正：SoloHostログイン用トークンの修正と、長いイメージ名の表示の修正が含まれる

SoloHostログイン用トークンの修正では、Pi Desktopを何日も動かしたままにするとSoloHostのログイン用トークン（ログイン状態を示す符号）の有効期限が切れてしまう問題を直した。長いイメージ名の表示の修正では、長いイメージ名が表示枠からはみ出してしまう表示上の問題を直し、正しく折り返すようにした。原文ではこの2件の修正が一覧の中と、その直後で重ねて説明されている。

これらの更新を合わせると、仕組みに自分で運用するアプリが増える中でSoloHostが強くなる。アプリの見つけやすさと安定性が高まれば、パイオニアが役立つアプリを見つけて動かしやすくなり、新しい開発者向け資料や問題調べの選択肢があれば、開発者がSoloHost向けのアプリを簡単に作り続けていける。

これらの改善は、Pi Desktopとノード（ネットワークを支えるコンピューター）の実用性をブロックチェーンの土台を超えて広げるというSoloHostのより大きな役割を支えるものであり、パイオニアに自分のコンピューターを自分で運用するアプリに使う方法を増やし、開発者にSoloHostへアプリを作って持ち込む道具を増やすものである。
