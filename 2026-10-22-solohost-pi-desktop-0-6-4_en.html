Pi Desktop Version 0.6.4: Easier Remote Access and Stronger SoloHost App Protections

Published: October 22, 2026

Categories: developer, update

Original article

This page is a plain-English summary of an article from the official Pi Network blog. It is not a full translation. Difficult words and expressions are explained in simple words. For the exact wording, see the original article.

Pi Desktop version 0.6.4 updates remote access for SoloHost and makes it easier and safer. Pioneers (people who use Pi) can now open apps that run on their own computer through the Pi Browser, without setting up their home router. This release also includes stronger protections for SoloHost apps and small improvements to the screens.

Easier and safer remote access to SoloHost apps

With Pi Desktop 0.6.4, remote access to SoloHost apps becomes much easier. Since it began, SoloHost has let a Pioneer's own computer work as their server. From the mobile SoloHost app inside the Pi Browser, a Pioneer can remotely open supported apps running on their desktop, such as AI agents (programs that use AI to do tasks on their own).

Before, setting up this remote connection required changing the home router, and it did not work on some networks.

With Pi Desktop 0.6.4, those router changes are no longer needed. Pi Desktop now sets up the connection without asking the user to open ports (entry points for network communication) on their home network. This removes a major technical barrier to remote access for SoloHost apps, and makes self-hosted apps (apps you run on your own computer) more convenient and easier to reach.

Remote access is still something each Pioneer chooses to turn on. Pioneers who set up remote access before can switch to the new connection by simply choosing "Reconnect" on the remote access screen.

Stronger protection for the apps you run

Along with simpler remote access, Pi Desktop 0.6.4 gives more protection to the computer that runs SoloHost apps.

The system now provides technical support to check that each app can access only its own files and network. This lowers the risk that an app could reach other parts of the user's computer, the Pi Node, or another app's data. This check is done before installation and each time an individual app starts.

The same check also runs when an app is first published. It helps find and stop apps that do not pass these checks from entering the SoloHost catalog. In this way, these risks are reduced at several stages: publishing, installation, and starting the app. Pioneers should still judge each app and package themselves, and install them at their own responsibility.

This release also includes small screen improvements, including an update to the Pi Node port-opening screen.

Together, these changes support a more accessible self-hosting experience. In other words, apps running on your own computer become easier to reach, and the protection over what those apps can access becomes stronger.

Pi Mainnet successfully upgraded to Protocol 28

Pi Mainnet also completed its upgrade to Protocol 28 on October 16, 2026. This upgrade improves how the network handles delays in transaction data, and makes it easier for developers to maintain smart contracts (programs that carry out the terms of an agreement automatically). It includes the ability to upgrade a group of smart contracts at once, and to change stored data more safely as apps grow.
